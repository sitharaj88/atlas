Atlas has nine paths. They overlap and feed each other — but you have to start somewhere. Answer three quick questions and we'll point you at a path that fits where you are today.

## Or pick directly

Already know what you need? Jump in:

- **Total beginner.** Have never built a webpage, not sure what HTML stands for. → [Foundations of the Web](/paths/foundations/)
- **I can build pages, but my CSS is shaky.** → [Modern CSS & Design Systems](/paths/modern-css/)
- **I write JS, want better types.** → [TypeScript Mastery](/paths/typescript/)
- **I want to learn React (or compare frameworks).** → [Frontend Frameworks](/paths/frontend-frameworks/)
- **I want to build full apps, end-to-end.** → [Full-Stack Web Development](/paths/full-stack/)
- **My site is slow / inaccessible / unfindable.** → [Performance, A11y & SEO](/paths/performance-a11y-seo/)
- **I keep breaking prod, need a safety net.** → [Testing & Quality](/paths/testing/)
- **I want to deploy and operate web apps confidently.** → [DevOps for Web](/paths/devops/)
- **I want to ship the cutting-edge stuff.** → [The Modern Frontier](/paths/frontier/)
