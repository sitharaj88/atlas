## 2026-05-08 · Atlas v0.1 — public launch

The first public release of Atlas is live. What ships in v0.1:

- **9 learning paths**, with module outlines for ~250 lessons.
- **8 fully-written sample lessons** to lock in the template — across Foundations, Modern CSS, TypeScript, Frontend Frameworks, Full-Stack, Performance/A11y, Testing, and DevOps.
- **3 cheatsheets** — Flexbox, Git, HTTP status codes.
- **1 roadmap** — Frontend.
- **1 build-along project** — Markdown blog with Astro.
- **~50 glossary entries.**
- **Reference** sections for HTML, CSS, JavaScript, and Web APIs (overview level — per-element/property pages coming soon).
- **Live playgrounds** (Sandpack) embedded in lessons.
- **Quizzes** with persisted answers.
- **Progress tracking** — checkmarks in sidebar, percent-complete on path pages.
- **Search** — Pagefind, hit `/`.
- **Dark/light mode** — system-aware, manual override.
- **Resume banner** — pick up where you left off.
- **Custom domain ready** — placeholder CNAME, configurable base path.
- **CI/CD** — GitHub Actions workflow that deploys on every push to `main`.

The platform is the hard part; lessons are additive. From here, content fills in incrementally — and you can [help](/contribute/).
