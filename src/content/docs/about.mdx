## The mission

The web is the largest learning platform humanity has ever built — and the worst-organized. There are dozens of excellent resources for any topic, but no opinionated, modern, beautiful, *coherent* destination that takes a learner all the way through.

**Atlas exists to be that destination.** Free forever. Open source. Built by working developers, in public.

## What's in it

- **9 learning paths** — from "what is HTTP?" to "shipping a production full-stack app," covering frontend, full-stack, performance, accessibility, testing, DevOps, and the modern frontier (edge, AI, real-time).
- **Reference** — learner-friendly docs for HTML, CSS, JavaScript, and the Web Platform.
- **Cheatsheets** — printable, beautifully designed one-pagers.
- **Roadmaps** — visual graphs of the landscape.
- **Projects** — build-along tutorials for portfolio-ready apps.
- **Glossary** — definitions for every bit of jargon, hover-tooltips throughout.

## What's it not

- **Not video.** Text + interactive code, designed for skim-and-scan.
- **Not gated.** No login, no paywall. Progress saves locally.
- **Not enterprise.** This isn't a corporate LMS. No certificates, no pretending you've "completed" anything.
- **Not omniscient.** We have opinions. Other paths exist. Read widely.

## The stack

Atlas itself is a showcase of what it teaches:

- **Astro 5 + Starlight** — static site, content collections, MDX.
- **React** — the few interactive islands (playgrounds, quizzes, roadmaps).
- **Sandpack** — embedded live playgrounds.
- **Pagefind** — instant client-side search.
- **Zustand + localStorage** — progress and quiz state.
- **TypeScript strict** — across the board.
- **Biome** — formatting and linting.
- **GitHub Pages** — hosting, free, fast.
- **GitHub Actions** — manual-trigger deploy from the Actions tab (so a typo fix doesn't ship until you're ready).
