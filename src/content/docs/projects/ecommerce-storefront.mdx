## What you'll build

- Product listing page (server-rendered).
- Add to cart (client state).
- Checkout via Stripe Checkout.
- Success and cancel pages.
- Webhook to fulfill the order.

## Stack

- **Astro + React islands** — fastest content + cart island.
- **Hono** — webhook endpoint.
- **Stripe** — payments (test mode, free).
- **SQLite** — product catalog (or hardcode if you want zero infra).

## Setup

```bash
pnpm create astro@latest ecom -- --template minimal --typescript strict
cd ecom
pnpm add @astrojs/react @astrojs/node react react-dom stripe
pnpm add -D @types/react @types/react-dom
```

Get a Stripe **test-mode** secret key from dashboard.stripe.com → API keys. Set `STRIPE_SECRET_KEY` in `.env`.

## Step 3 — Checkout endpoint

```ts
// src/pages/api/checkout.ts
import Stripe from 'stripe';
const stripe = new Stripe(process.env.STRIPE_SECRET_KEY!);

export async function POST({ request }) {
  const { items } = await request.json();
  const session = await stripe.checkout.sessions.create({
    mode: 'payment',
    line_items: items.map(i => ({
      price_data: {
        currency: 'usd',
        unit_amount: i.price,
        product_data: { name: i.name },
      },
      quantity: i.quantity,
    })),
    success_url: `${request.headers.get('origin')}/thanks?session_id={CHECKOUT_SESSION_ID}`,
    cancel_url: `${request.headers.get('origin')}/cancel`,
  });
  return Response.redirect(session.url!, 303);
}
```

Cart submits to `/api/checkout`; user lands on Stripe; pays with test card `4242 4242 4242 4242`.

## Step 4 — Webhook

```ts
// src/pages/api/webhook.ts
const endpointSecret = process.env.STRIPE_WEBHOOK_SECRET!;

export async function POST({ request }) {
  const sig = request.headers.get('stripe-signature')!;
  const body = await request.text();
  const event = stripe.webhooks.constructEvent(body, sig, endpointSecret);

  if (event.type === 'checkout.session.completed') {
    const session = event.data.object;
    await fulfillOrder(session); // mark in DB, send email, etc.
  }
  return new Response('ok');
}
```

Use `stripe listen --forward-to localhost:4321/api/webhook` to test locally.

## Step 5 — Success / cancel pages

Just two static pages. The webhook is the source of truth that the order completed.
