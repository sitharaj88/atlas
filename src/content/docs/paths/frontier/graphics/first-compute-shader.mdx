## The shape

```ts
const adapter = await navigator.gpu.requestAdapter();
const device = await adapter!.requestDevice();

const shader = device.createShaderModule({ code: `
  @group(0) @binding(0) var<storage, read_write> data: array<f32>;
  @compute @workgroup_size(64)
  fn main(@builtin(global_invocation_id) id: vec3u) {
    data[id.x] = data[id.x] * 2.0;
  }
`});

// (Buffer creation, pipeline setup, dispatch — ~30 lines of plumbing)
```

GPUs run thousands of threads in parallel. For data-parallel work (multiplying every element of an array), you can outperform CPU code by 10-100×.

## What's possible in the browser

- Image filters (blur, sharpen) on huge images.
- ML inference (TensorFlow.js, ONNX Runtime Web with WebGPU backend).
- Physics simulations.
- Real-time generative art.

## Limits

- Verbose plumbing. Use libraries (TF.js, ONNX, Hugging Face Transformers.js).
- WebGPU requires a recent browser. Fall back to WebGL or CPU for older ones.
- Mobile WebGPU support is recent.
