## Canvas 2D

```js
const ctx = canvas.getContext('2d');
ctx.fillRect(0, 0, 100, 100);
```

CPU-rendered 2D. Great for games up to a few thousand sprites, charts, generative art.

## WebGL

OpenGL ES 3.0 in the browser. GPU-accelerated, but verbose API and 15 years old.

## WebGPU

Modern, lower-level GPU API. Compute shaders. Better debugging. Smaller bundle for what you can do. New code should target WebGPU; WebGL will remain for years for compat.

## Pick

- **Static charts** — SVG or Canvas 2D.
- **2D games, particle systems** — Canvas 2D or PixiJS.
- **3D, complex graphics** — WebGPU (or libraries: Three.js, Babylon.js — they support both).
- **GPU compute** (image processing, ML) — WebGPU compute shaders.
