## The pattern

```tsx
export default async function Page() {
  return (
    <main>
      <Header />                                {/* fast — synchronous */}
      <Suspense fallback={<Spinner />}>
        <SlowFeed />                             {/* awaits data, takes 800ms */}
      </Suspense>
      <Suspense fallback={<Spinner />}>
        <RecommendedList />                      {/* takes 1200ms */}
      </Suspense>
    </main>
  );
}
```

The HTML for `<Header />` flushes immediately. The Suspense boundaries' HTML streams in as their data resolves — no waiting for the slowest one to start rendering.

## Why this is amazing

- **First Contentful Paint** — fastest possible.
- **No spinner-on-everything** — only the slow parts show fallback.
- **Parallel data fetching** — siblings start fetching at the same time.
- **No waterfalls** — without RSC, you'd often see "fetch user, then fetch user's posts, then render."
