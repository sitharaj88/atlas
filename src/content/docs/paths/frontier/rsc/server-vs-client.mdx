## Server components (default)

✅ Can: be `async`, `await` data, use server-only modules (`fs`, DB clients), read secrets, read request headers.

❌ Can't: use `useState`, `useEffect`, browser APIs, attach `onClick`.

## Client components (`'use client'` at top of file)

✅ Can: useState/useEffect, browser APIs, event handlers, interactive logic.

❌ Can't: import server components directly, access server-only modules.

## Composition rule

Server components can render client components and pass props. Client components **can't import server components** — but can receive them as `children`:

```tsx
// Server (parent)
<ClientShell>
  <ServerOnlyChart data={await getData()} />
</ClientShell>
```

The server renders `ServerOnlyChart` first, then hands its rendered output to `ClientShell` as a prop. The client never sees the chart's source.
