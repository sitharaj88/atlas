## The problem

Classic React ships every component to the browser, even ones that never re-render and have no interactivity. A Markdown blog ships a 200KB Markdown parser to render text the user sees as plain HTML.

## RSC's answer

Components marked as "server components" run on the server, render to a serialized format, and **never ship to the client**. Only the genuinely interactive components ("client components" with `'use client'`) get hydrated.

## Bundle math

| | Classic React | RSC |
|---|---|---|
| Markdown parser | shipped | server-only |
| DB client | (you'd never ship it; required separate API) | server-only, called directly |
| Like button | shipped | shipped |
| Layout, header, footer | shipped | server-only |

For content-heavy pages, JS bundle drops 70-90%.
