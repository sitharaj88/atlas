## Astro

Components render to static HTML at build (or request) time. Zero JS by default. Add interactive components ("islands") with `client:` directives:

```astro
<Counter client:visible />     <!-- hydrates when scrolled into view -->
<Modal client:idle />           <!-- hydrates after the browser is idle -->
<Critical client:load />        <!-- hydrates immediately -->
```

Astro is what powers this Atlas site (via Starlight).

## Fresh

Deno-native islands framework. Same idea — server renders by default, sprinkle interactive bits. Pairs with Deno Deploy for global edge serving.

## When islands beat full-SPA

- Content sites — docs, blogs, marketing.
- Sites where most pages are static and a few bits are interactive.

## When full-SPA wins

- Apps where most of the page is interactive (dashboards, editors).
- State-heavy interactions across many components.
