## Cold-start cost

- **AWS Lambda (Node)** — 200-800ms.
- **Vercel Edge** — 50-150ms.
- **Cloudflare Workers** — 5-10ms (V8 isolate, not container).
- **Always-on server (Fly, Render)** — 0ms.

## When cold starts hurt

- Low-traffic endpoints. After 5 min idle, container sleeps; first request lags.
- Functions with heavy startup (DB connection pools, ML model loading).
- Latency-critical APIs.

## Mitigations

- **Provisioned concurrency** (AWS) — keep N instances warm. Costs more.
- **Edge runtimes** — much faster cold starts.
- **Connection-pool services** (Hyperdrive, Neon) — share pools across cold starts.
- **Always-on hosting** for hot paths.

## Picking

- High-traffic or latency-critical → always-on (Fly, Render) OR Cloudflare Workers.
- Bursty / event-driven → AWS Lambda or Vercel Functions.
- Global low-latency → Cloudflare Workers.
