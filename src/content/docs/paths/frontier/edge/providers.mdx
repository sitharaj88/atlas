## Cloudflare Workers

300+ edge locations. Fastest cold starts. Cheapest at scale. Tightest runtime constraints (10ms CPU per request on free tier).

Pair with: D1 (SQLite at edge), Workers KV, R2 (S3-compat object storage), Durable Objects (stateful per-key).

## Vercel Edge

Built into Next.js's `runtime: 'edge'` opt-in. Easiest if you're already on Vercel. Slightly fewer locations than Cloudflare.

## Deno Deploy

Deno's edge platform. TypeScript-native, npm-compatible. Fewer locations than Cloudflare.

## All speak the same standards

`Request`, `Response`, `fetch`, `streams` — all three platforms support the same Web Standards. Same Hono app deploys to all three.
