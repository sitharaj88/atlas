## Real-world wins

- **Photoshop on the web** — Adobe.
- **Figma's renderer** — handles huge documents at 60fps.
- **FFmpeg.wasm** — video transcoding in browser.
- **SQL.js, sqlite-wasm** — SQLite in the browser.
- **Pyodide** — Python in the browser.
- **TensorFlow.js with Wasm backend** — ML inference 5–10× faster.
- **Codec libraries** — AV1 decoders, image format polyfills.

## Where Wasm doesn't help

- Form-driven CRUD apps.
- Anything bottlenecked on network or DOM.
- Simple animations (CSS transforms still beat).

## Engineering cost

Wasm projects ship in megabytes (often 1-5 MB). Code-split aggressively, lazy-load on demand. Compile via wasm-opt, brotli-compress.
