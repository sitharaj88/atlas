## Loading

```ts
const wasm = await WebAssembly.instantiateStreaming(fetch('/lib.wasm'));
const { add } = wasm.instance.exports;
add(2, 3);   // 5
```

## With higher-level tooling

Most teams use **wasm-bindgen** (Rust) or AssemblyScript:

```rust
// Rust
use wasm_bindgen::prelude::*;

#[wasm_bindgen]
pub fn greet(name: &str) -> String {
    format!("Hello, {name}")
}
```

Build with `wasm-pack` → produces JS glue + .wasm file. From the consumer side it's just an import.

## Memory

Wasm exposes a linear memory buffer. Strings, structs, and arrays are passed via byte offsets — bindgen tools wrap this for you.

## Performance

Crossing the JS/Wasm boundary has a small cost (microseconds). For tight loops, do work entirely in Wasm; cross over only at boundaries.
