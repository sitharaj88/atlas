## Yjs

Open-source CRDT library. You bring your own transport (WebSocket, WebRTC, Hocuspocus server).

```ts
import * as Y from 'yjs';
import { WebsocketProvider } from 'y-websocket';

const doc = new Y.Doc();
const provider = new WebsocketProvider('wss://api.atlas.dev/yjs', 'room-1', doc);
const items = doc.getArray('items');
items.observe(() => render(items.toArray()));

items.push(['hello']);   // syncs to other users in real time
```

Pairs with editor frameworks (CodeMirror, ProseMirror, Tiptap, Slate) for collaborative editing.

## Liveblocks

Managed CRDT-as-a-service. Pre-built React/Vue/Svelte hooks, presence, comments, threads. You skip the transport layer entirely.

```tsx
const others = useOthers();         // who else is here
const [todos, setTodos] = useStorage((root) => root.todos);
```

Pay-as-you-go pricing.

## Pick

- **Yjs** — full control, self-host, open source.
- **Liveblocks** — fast to build, pay for the convenience.
