## What "presence" looks like

- Avatars of who's online.
- Cursor positions in the document.
- "X is typing" indicators.
- Selection highlights ("X selected this paragraph").

These are **ephemeral** — they don't need to persist. Liveblocks' `useOthers()` gives you exactly this.

## Conflict-free editing

The CRDT handles merging two simultaneous text edits at the same position. No "ask the user to resolve conflict" UI.

For richer collaboration (commenting, suggestions, branching), look at:

- **Liveblocks Comments** — threads on any element.
- **Tiptap with Yjs** — production-grade collaborative rich text.
- **Loro** — newer, fast CRDT library.

## Trade-offs

- Network costs scale with users × frequency × document size.
- Storage of CRDT history can be hefty over time. Periodically snapshot + compact.
- Initial sync can be slow for huge docs — paginate or lazy-load.
