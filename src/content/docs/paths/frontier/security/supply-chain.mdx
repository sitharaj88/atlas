## The threats

- **Malicious packages** — typo-squatted names ("expres" instead of "express"), or hijacked legitimate ones.
- **Postinstall scripts** that exfiltrate env vars.
- **Compromised maintainer accounts**.
- **Transitive dependencies** you never audited.

## Hygiene

- **Pin versions.** `pnpm-lock.yaml` is your friend; commit it.
- **`pnpm audit`** in CI. Fail on high/critical.
- **Disable postinstall scripts** by default: `npm config set ignore-scripts true` (then opt in for trusted packages).
- **Renovate / Dependabot** — automated updates with diff visibility.
- **Verify package signing** — provenance via `npm install --audit-signatures`.

## Read what you install

```bash
pnpm dlx npq install some-package    # nags about red flags before installing
```

For a critical dependency, **read the package.json scripts**, **scan the source size** (10KB pkg with 50MB postinstall is suspicious).

## Stay smaller

The more deps you have, the bigger the surface. Audit lock files in PRs. Push back on adding packages for tiny needs.
