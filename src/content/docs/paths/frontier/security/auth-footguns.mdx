## Top mistakes

- **JWTs in localStorage.** XSS-readable. Use HTTP-only cookies.
- **Returning the password hash** in API responses. Strip it.
- **Auth check on the client only.** Always re-check on the server.
- **No CSRF protection** when using cookie-auth. SameSite=Lax helps; double-submit token + Origin check is the belt-and-suspenders.
- **Open redirects.** `?next=...` query params used in redirects without a same-origin check.
- **Timing attacks.** String comparison of tokens with `===` (not constant-time). Use `timingSafeEqual` (Node) or library.
- **Verbose error messages** that leak whether an email is registered.
- **Long sessions with no expiration.** 30 days max is reasonable; refresh tokens for "remember me."
- **Magic-link / OTP without rate limiting.** Attackers spray.

## Patterns that work

- HTTP-only cookies for sessions.
- Server-side authz check on every request.
- Use a library (Lucia, Auth.js, BetterAuth) — don't roll your own.
- Centralize the auth middleware so it's hard to forget.
- Audit logs for sensitive actions.
