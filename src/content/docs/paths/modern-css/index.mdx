## Path map

### Module 1 · The Cascade, Reloaded
- The CSS cascade in 2026 — origin, layer, specificity, order
- Cascade layers (`@layer`) — never lose a specificity war again
- The `:where()` and `:is()` ergonomics

### Module 2 · Layout, Modern
- Flexbox you actually understand
- Grid: subgrid, named lines, dense packing
- Container queries — components that respond to themselves
- `:has()` — the parent selector we waited a decade for
- [Container queries](/paths/modern-css/layout/container-queries/) ← **sample lesson**

### Module 3 · Typography & Color
- Fluid typography with `clamp()`
- Variable fonts and OpenType features
- Modern color: `oklch`, `color-mix()`, P3
- Accessible contrast in practice

### Module 4 · Motion & View Transitions
- `prefers-reduced-motion` from day one
- Scroll-driven animations
- View Transitions API for SPA-like navigation in MPAs

### Module 5 · Design Tokens & Theming
- Tokens vs. variables vs. utilities
- Light/dark/high-contrast theming with CSS variables
- Building a token pipeline (Style Dictionary)

### Module 6 · CSS Architecture
- Tailwind CSS — the utility-first mental model
- CSS Modules — scoped styles in component code
- Vanilla Extract — types for your styles
- BEM, ITCSS, CUBE — when each shines

### Module 7 · Build a Design System
- From scratch: tokens → primitives → components
- Documenting components with Storybook
- Versioning and consuming a design system across apps
