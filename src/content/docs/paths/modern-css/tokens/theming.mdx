> **What you'll learn.** The standard CSS pattern for theming — one source of truth, fast switching, system-respecting.

## The pattern

```css
:root {
  /* default (light) — semantic tokens */
  --bg: #fff;
  --text: #0b1b2b;
  --link: #1c3963;
  --hairline: rgba(11,27,43,0.1);
}

:root[data-theme='dark'] {
  --bg: #0b1b2b;
  --text: #ecf0f7;
  --link: #f5b14a;
  --hairline: rgba(255,255,255,0.1);
}

@media (prefers-color-scheme: dark) {
  :root:not([data-theme]) {
    --bg: #0b1b2b;
    --text: #ecf0f7;
    /* ... */
  }
}
```

Three layers of preference:

1. Default = light.
2. System dark? Use dark (unless explicit override).
3. User clicked the toggle (`[data-theme='dark']`)? Use that.

## The toggle

```js
const root = document.documentElement;
const stored = localStorage.getItem('theme');
if (stored) root.dataset.theme = stored;

button.addEventListener('click', () => {
  const next = root.dataset.theme === 'dark' ? 'light' : 'dark';
  root.dataset.theme = next;
  localStorage.setItem('theme', next);
});
```

Apply the stored theme **before paint** to avoid flash:

```html
<script>
  const t = localStorage.getItem('theme');
  if (t) document.documentElement.dataset.theme = t;
</script>
```

Inline this script at the top of `<head>`.

## High-contrast theme

```css
:root[data-theme='hc'] {
  --bg: #000;
  --text: #fff;
  --link: #ff0;
  --hairline: #fff;
}

@media (prefers-contrast: more) {
  :root:not([data-theme]) { /* same as hc above */ }
}
```

`prefers-contrast: more` is enabled when the user requests increased contrast at the OS level.

<Callout variant="tip" title="Pick semantic tokens carefully">
The semantic names should describe role, not appearance. `--bg-card` not `--bg-white`. When dark mode flips the value, the role still applies.
</Callout>
