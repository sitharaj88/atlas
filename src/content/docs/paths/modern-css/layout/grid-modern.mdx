> **What you'll learn.** Grid features that solve advanced layout problems with one or two lines.

## Named lines

```css
.layout {
  display: grid;
  grid-template-columns:
    [page-start] 1fr [content-start] minmax(0, 60ch) [content-end] 1fr [page-end];
}

.full   { grid-column: page-start / page-end; }
.normal { grid-column: content-start / content-end; }
.aside  { grid-column: page-start / content-start; }
```

Lines named in `[brackets]` between track sizes. Items reference the names instead of numbers — readable and resilient.

## Named areas (revisited)

```css
.app {
  display: grid;
  grid-template-areas:
    "header header"
    "side   main"
    "footer footer";
  grid-template-columns: 200px 1fr;
  grid-template-rows: auto 1fr auto;
}
.header { grid-area: header; }
```

The visual ASCII layout *is* the layout — best for page shells.

## Subgrid

A grid child that wants to align with its parent's tracks:

```css
.parent {
  display: grid;
  grid-template-columns: 1fr 2fr 1fr;
}
.child {
  grid-column: 1 / -1;
  display: grid;
  grid-template-columns: subgrid;
}
```

The `child` uses the parent's three columns. Useful for forms (label, input, error all align across rows), card grids that need internal alignment.

## Dense packing

When items vary in size, gaps form. `dense` fills them:

```css
.gallery {
  display: grid;
  grid-template-columns: repeat(auto-fit, 12rem);
  grid-auto-flow: dense;
  gap: 1rem;
}
.gallery .wide { grid-column: span 2; }
```

`dense` reorders items visually to fill holes. Tab/screen-reader order stays in DOM order — be aware.

## Implicit tracks

```css
.list {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  grid-auto-rows: minmax(8rem, auto);  /* implicit row sizing */
}
```

`grid-auto-rows` sets sizing for any row Grid creates as items overflow.

## Auto-fit vs. auto-fill

- `auto-fit` collapses empty tracks. Items grow to fill the row.
- `auto-fill` keeps empty tracks. Items don't grow past their min.

```css
grid-template-columns: repeat(auto-fit,  minmax(14rem, 1fr));   /* fills width */
grid-template-columns: repeat(auto-fill, minmax(14rem, 1fr));   /* leaves slots */
```

Default to `auto-fit` for cards.

<Callout variant="tip" title="`grid-template` shorthand">
For layouts with named areas + tracks, `grid-template` combines areas and rows: `grid-template: "header header" auto / 200px 1fr;`. Concise but harder to read; named-line versions tend to win for clarity.
</Callout>
