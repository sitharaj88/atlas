> **What you'll learn.** The View Transitions API gives you native, accessible page-transition animations for free.

## Same-document transition

```js
async function showContent(html) {
  if (!document.startViewTransition) {
    main.innerHTML = html;
    return;
  }
  document.startViewTransition(() => {
    main.innerHTML = html;
  });
}
```

The browser captures a snapshot, runs your DOM update, then animates from old to new state. Default crossfade.

## Customize with names

```css
.hero { view-transition-name: hero; }

::view-transition-old(hero),
::view-transition-new(hero) {
  animation-duration: 600ms;
}

::view-transition-old(hero) { animation: slide-left 600ms; }
::view-transition-new(hero) { animation: slide-right 600ms; }
```

Elements with the same `view-transition-name` morph between states. Hero image grows from card to detail page — three lines of CSS.

## Cross-document (MPA) transitions

For traditional multi-page sites, opt in:

```css
@view-transition { navigation: auto; }
```

Now navigation between same-origin pages animates automatically. Astro and other static-site generators leverage this.

## With reduced motion

```css
@media (prefers-reduced-motion: reduce) {
  ::view-transition-old(*),
  ::view-transition-new(*) {
    animation: none;
  }
}
```

<Callout variant="tip" title="Pair with named transitions">
Mark your hero, header, and primary navigation with `view-transition-name`s; the rest crossfades. The result feels like a polished native app, with vanilla CSS.
</Callout>
