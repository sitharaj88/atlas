> **What you'll learn.** Variable fonts ship every weight and style in one file. Smaller download, more flexibility.

## Loading a variable font

```css
@font-face {
  font-family: 'Inter';
  src: url('/fonts/Inter.var.woff2') format('woff2-variations');
  font-weight: 100 900;     /* range of supported weights */
  font-style: normal;
  font-display: swap;
}
```

Now `font-weight: 437;` works (any number in the range, not just 400/700).

## font-variation-settings

For axes beyond weight (slant, optical size, width):

```css
h1 {
  font-family: 'Fraunces';
  font-variation-settings: 'opsz' 144, 'SOFT' 50;
  font-weight: 600;
}
```

Common axes: `wght` (weight), `wdth` (width), `slnt` (slant), `ital` (italic), `opsz` (optical size). Custom axes have uppercase names.

## OpenType features

```css
:root { font-feature-settings: 'cv11' 1, 'ss01' 1; } /* alternate glyphs */
.lining { font-feature-settings: 'lnum' 1; }   /* lining figures */
.tabular { font-variant-numeric: tabular-nums; } /* monospaced digits — for tables */
.no-ligatures { font-variant-ligatures: none; }
```

Use `font-variant-*` properties when available — they're the higher-level API. Fall back to `font-feature-settings` for raw control.

## Subsetting

Variable fonts can still be 200KB+. Subset to your character set:

```text
glyphhanger https://atlas.dev --subset='Inter-Variable.ttf'
```

Or use Google Fonts with `&text=...` to subset to a specific string.
