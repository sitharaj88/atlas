## Path map

This path moves from **how the web works** → **HTML5** → **CSS** → **JavaScript** → **the DOM and Web APIs** → **async and modules** → **accessibility primer**. Every module ends with a small project that uses everything before it.

### Module 1 · The Web Platform

What happens when you type a URL and hit Enter. HTTP, DNS, TCP/IP, browsers, the rendering pipeline. No code yet — just mental models that pay off forever.

- [How the web works](/paths/foundations/web-platform/how-the-web-works/) ← **start here**
- DNS, IP, and what `localhost` actually is _(coming soon)_
- HTTP requests and responses, hands-on with curl _(coming soon)_
- The browser rendering pipeline _(coming soon)_

### Module 2 · HTML5

Semantic markup, forms, media, accessibility built-in.

- HTML, the contract you sign with the browser _(coming soon)_
- Document structure and semantics _(coming soon)_
- Forms — inputs, validation, submission _(coming soon)_
- Images, video, audio, and the picture element _(coming soon)_
- Accessibility primer: ARIA without the footguns _(coming soon)_

### Module 3 · CSS Fundamentals

The cascade, the box model, layout that doesn't fight you.

- The cascade and specificity, demystified _(coming soon)_
- The box model (and `box-sizing: border-box`) _(coming soon)_
- Flexbox, the friendly version _(coming soon)_
- Grid, the powerful version _(coming soon)_
- Responsive design with relative units _(coming soon)_

### Module 4 · JavaScript Basics

Modern JS through ES2026. No "var", no "callback hell."

- Values, types, and operators _(coming soon)_
- Variables, scope, hoisting _(coming soon)_
- Functions, including arrow and rest/spread _(coming soon)_
- Arrays and objects (and destructuring) _(coming soon)_
- Control flow and iteration _(coming soon)_

### Module 5 · The DOM

How JavaScript talks to the page.

- Selecting and traversing nodes _(coming soon)_
- Mutating the DOM (carefully) _(coming soon)_
- Events, delegation, and bubbling _(coming soon)_

### Module 6 · Web APIs

Beyond the DOM — what the browser hands you for free.

- `fetch`, the modern HTTP client _(coming soon)_
- Storage — localStorage, sessionStorage, IndexedDB _(coming soon)_
- Geolocation, clipboard, Web Share — practical APIs _(coming soon)_

### Module 7 · Asynchronous JavaScript

The hardest part of the language, made calm.

- Callbacks → Promises → async/await _(coming soon)_
- Error handling that doesn't bury bugs _(coming soon)_
- Concurrency: `Promise.all`, `allSettled`, `race`, `any` _(coming soon)_

### Module 8 · Modules & Tooling

How real apps are organized.

- ES Modules, native `import`/`export` _(coming soon)_
- Bundlers vs. native — when each makes sense _(coming soon)_
- Vite, the modern dev server _(coming soon)_

### Module 9 · Accessibility Primer

A11y you actually understand and apply.
