## Reusable workflow

A whole workflow you can call from another:

```yaml
# .github/workflows/test.yml
on: workflow_call

jobs:
  test:
    runs-on: ubuntu-latest
    steps: [...]
```

```yaml
# called from another workflow
jobs:
  test:
    uses: ./.github/workflows/test.yml
```

## Composite action

A reusable set of steps:

```yaml
# .github/actions/setup/action.yml
runs:
  using: composite
  steps:
    - uses: pnpm/action-setup@v4
    - uses: actions/setup-node@v4
      with: { node-version: 20, cache: pnpm }
    - run: pnpm install --frozen-lockfile
      shell: bash
```

Used as:

```yaml
- uses: ./.github/actions/setup
```

## Pick the right level

- **Composite action** — small reusable steps (setup, lint, smoke).
- **Reusable workflow** — larger complete jobs (test, deploy).
