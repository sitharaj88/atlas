## Matrix

```yaml
strategy:
  matrix:
    node: [18, 20, 22]
    os: [ubuntu-latest, macos-latest]
runs-on: ${{ matrix.os }}
steps:
  - uses: actions/setup-node@v4
    with: { node-version: ${{ matrix.node }} }
```

Runs the job 6 times (3 nodes × 2 OS) in parallel.

## Caching

`actions/setup-node@v4` with `cache: pnpm` caches `node_modules` keyed by lockfile hash:

```yaml
- uses: actions/setup-node@v4
  with: { node-version: 20, cache: pnpm }
```

For arbitrary paths:

```yaml
- uses: actions/cache@v4
  with:
    path: ~/.cache/playwright
    key: pw-${{ hashFiles('pnpm-lock.yaml') }}
```

## Artifacts

Pass files between jobs (build → deploy) or save for debugging:

```yaml
# In build job
- uses: actions/upload-artifact@v4
  with: { name: dist, path: dist }

# In deploy job
- uses: actions/download-artifact@v4
  with: { name: dist, path: dist }
```

For traces / logs from failures:

```yaml
- if: failure()
  uses: actions/upload-artifact@v4
  with: { name: traces, path: test-results }
```
