## reflog — your time machine

Every move HEAD makes is logged for ~90 days:

```bash
git reflog
# 1a2b3c HEAD@{0}: commit: feat: add foo
# 9d8e7f HEAD@{1}: rebase: onto main
# 5c6b4a HEAD@{2}: commit: WIP

git reset --hard HEAD@{2}   # jump back to the WIP state
```

If you ever "lose" work, `git reflog` is the first thing to try.

## cherry-pick

Copy one (or a range of) commits onto the current branch:

```bash
git cherry-pick abc123              # one commit
git cherry-pick A^..B               # range, exclusive A, inclusive B
```

Useful for hotfixes you want on both `main` and a release branch.

## bisect

Binary-search for the commit that broke a feature:

```bash
git bisect start
git bisect bad                      # current is bad
git bisect good v1.2.0              # this version was good
# Git checks out a midpoint
# Test it; mark good or bad
git bisect good   # or bad
# Repeat until found
git bisect reset
```

Automated:

```bash
git bisect run pnpm test --run
```

Git runs the script at each midpoint; exit code decides good/bad. Finds the offending commit in `log2(N)` steps.
