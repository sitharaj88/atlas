## Three things to know

**Commits** — snapshots of the working tree, plus a parent pointer (or two for merges). Identified by SHA.

**Refs** — named pointers to commits. Branches (`main`) and tags (`v1.0.0`) are refs. **HEAD** is "which ref am I on right now."

**The index** (a.k.a. "staging area") — the next commit you're about to make. `git add` updates the index; `git commit` turns the index into a commit.

## The three trees

```text
Working tree    ←→  Index (staging)  ←→  HEAD (last commit)
   git add ────►       git commit ────►
                ◄──── git checkout       ◄──── git reset
```

Almost every Git command moves data between these three.

## Branches are just labels

```bash
git branch                  # list local branches
git switch -c feature/x     # create + switch
```

A "branch" is a movable pointer. `main` and `feature/x` are both labels pointing at commits. New commits move the current branch's pointer forward.
