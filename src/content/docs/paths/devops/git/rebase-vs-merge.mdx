## Merge

Combines two branches by creating a new merge commit:

```text
A---B---C   main
     \
      D---E   feature
       \
        ----M   merge commit (parents: C, E)
```

Preserves history "as it happened."

## Rebase

Replays your commits on top of the target:

```text
A---B---C---D'---E'   main (after rebase)
```

Linear history. The original D, E disappear from your branch.

## Rules of thumb

- **Rebase BEFORE you push** to clean up local history.
- **Merge AFTER you push** to share. Don't rewrite shared history.
- **Squash-and-merge** in PRs is fine — collapses noisy commits to one.

## Force-push safety

`git push --force` is dangerous on shared branches. Use `--force-with-lease` — it refuses to overwrite if someone else has pushed since you fetched.

```bash
git push --force-with-lease origin feature/x
```
