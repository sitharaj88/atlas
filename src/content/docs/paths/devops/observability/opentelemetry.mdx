## What it is

A standard SDK + protocol for emitting logs, metrics, traces. Your code uses the OTel API; you choose where the data goes.

## Auto-instrumentation

```ts
import { NodeSDK } from '@opentelemetry/sdk-node';
import { getNodeAutoInstrumentations } from '@opentelemetry/auto-instrumentations-node';

const sdk = new NodeSDK({
  serviceName: 'atlas-api',
  instrumentations: [getNodeAutoInstrumentations()],
});
sdk.start();
```

Picks up Express, Fastify, Hono, Postgres, Redis, fetch, AWS SDK — automatically.

## Send to anywhere

OTel exporters target:
- **Honeycomb, Datadog, New Relic** — vendors.
- **Grafana Tempo, Loki, Mimir** — open source.
- **AWS X-Ray, GCP Cloud Trace** — clouds.

You can switch by changing config, not code.
