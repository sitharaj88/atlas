## The popular options

- **Sentry** — best at error tracking with stack traces, releases, breadcrumbs. Decent metrics + traces now too.
- **Honeycomb** — the best DX for distributed tracing. Pricey but worth it for heavy-traffic services.
- **Grafana stack (Loki + Tempo + Mimir)** — open source, self-hostable. Steep learning curve, full control.
- **Datadog** — all-in-one. Expensive but smooth.
- **New Relic** — similar.
- **AWS CloudWatch / GCP Operations** — built into the cloud, cheaper if you live there.

## Pick by scale

- **Solo / small team** — Sentry + cloud built-ins (CloudWatch, etc.).
- **Growing SaaS** — Sentry for errors + Honeycomb or Datadog for traces.
- **Enterprise / cost-sensitive** — Grafana stack self-hosted.

## What to wire first

1. Errors → Sentry.
2. Logs (structured) → wherever's cheap.
3. Traces (auto-instrumented) → starts free with most platforms.
