## The three

- **Logs** — discrete events. "User signed up." "Payment failed."
- **Metrics** — numerical aggregates over time. "p95 latency: 320ms."
- **Traces** — the path of a single request through services.

## When to reach for each

| Question | Pillar |
|---|---|
| "Why did THIS request fail?" | Trace |
| "How is the system doing overall?" | Metrics |
| "What happened when?" | Logs |

## Cardinality

High-cardinality data (user IDs, request IDs) belongs in logs and traces, not in metrics — adding millions of distinct labels blows up your metric store.
