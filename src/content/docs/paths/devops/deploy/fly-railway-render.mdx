## When you outgrow serverless

- Long-lived WebSockets.
- Persistent processes (queues, schedulers).
- Specific runtime (you need Bun, Deno, Rust).
- Custom binaries (FFmpeg, ML models).
- Multi-region with persistent storage.

## Fly.io

Run any Docker image globally. `fly launch`, `fly deploy`. Postgres, Redis, volumes — all available. Excellent for full-stack apps.

```bash
fly launch
fly deploy
fly postgres create
fly postgres attach
```

## Railway

Push-to-deploy. Auto-detects framework. Built-in Postgres, Redis. Simpler than Fly; pricier per resource.

## Render

Heroku-like. Web services, background workers, cron jobs, managed Postgres. The PaaS for people who miss old Heroku.

## Pick

- **Fly** — global, control over Docker, custom runtimes.
- **Railway** — fastest start, smallest projects.
- **Render** — middle ground, good DX, mature.
