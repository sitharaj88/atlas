## When VPS makes sense

- Cost matters more than convenience.
- You need full control (custom binaries, kernel modules).
- A learning project — running prod end-to-end teaches a lot.

## Hosts

- **Hetzner** — best price/performance. EU-based.
- **Digital Ocean** — solid US options.
- **Linode (Akamai)** — mature, decent prices.
- **AWS Lightsail** — simple AWS entry.

## Minimum viable stack

- **Linux** (Ubuntu LTS or Debian).
- **Caddy** — auto-HTTPS reverse proxy.
- **Docker / docker compose** — your app + DB.
- **systemd** — keep things running.
- **fail2ban** + **UFW** — basic security.
- **Let's Encrypt** (Caddy handles automatically).

## A working `Caddyfile`

```caddy
atlas.dev {
  reverse_proxy localhost:3000
}
```

Caddy gets you HTTPS, HTTP/2, and HTTP/3 in three lines.

## Backup strategy

If your DB is on the VPS, backups are your responsibility. **Always**:

- Daily DB dump to an offsite bucket (S3, R2).
- Test the restore quarterly.
