## What they all do

Watch your repo, build on push, deploy globally on a CDN, manage SSL/DNS, run "edge functions" for dynamic logic. Rollback is one click.

## How they differ

- **Vercel** — best Next.js DX, generous free tier, opinionated. Cost ramps with traffic and features.
- **Netlify** — strong static + functions story, simple pricing. Less specialized for any one framework.
- **Cloudflare Pages + Workers** — cheapest at scale, fastest edge runtime, excellent for global. Workers runtime is a Web-Standards subset of Node.

## Pick by stack

| Stack | First choice |
|---|---|
| Next.js, full-stack | Vercel |
| Astro, static + sprinkles | Cloudflare Pages |
| SvelteKit, Nuxt | Any of the three |
| Public API at scale | Cloudflare Workers |
| Simple JAMstack | Netlify |

## The deploy preview superpower

All three give every PR a unique preview URL. Reviewers click, test, comment. **Don't ship without this.**
