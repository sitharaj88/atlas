## A typical compose file

```yaml
# compose.yml
services:
  app:
    build: .
    ports: ['3000:3000']
    environment:
      DATABASE_URL: postgres://atlas:atlas@db:5432/atlas
    depends_on: { db: { condition: service_healthy } }

  db:
    image: postgres:17
    environment: { POSTGRES_USER: atlas, POSTGRES_PASSWORD: atlas, POSTGRES_DB: atlas }
    ports: ['5432:5432']
    volumes: ['db-data:/var/lib/postgresql/data']
    healthcheck:
      test: ['CMD-SHELL', 'pg_isready -U atlas']
      interval: 2s

  redis:
    image: redis:7
    ports: ['6379:6379']

volumes:
  db-data:
```

```bash
docker compose up -d        # start in background
docker compose logs -f app
docker compose down         # stop
```

## Patterns

- **Per-service `Dockerfile.dev`** for hot-reload during dev.
- **Volumes** for DB persistence and source mounting.
- **`depends_on` with `condition: service_healthy`** so app waits for DB.

For production, prefer your platform (Fly, Railway, k8s) — compose is a dev tool.
