## What a container is

A Linux process running with namespaces (its own view of filesystem, network, processes) and cgroups (CPU/memory limits). The container's filesystem comes from an **image** — a stack of read-only layers.

## Hello, Docker

```dockerfile
FROM node:20-alpine
WORKDIR /app
COPY package.json pnpm-lock.yaml ./
RUN corepack enable && pnpm install --frozen-lockfile
COPY . .
RUN pnpm build
CMD ["node", "dist/server.js"]
```

```bash
docker build -t atlas-api .
docker run -p 3000:3000 atlas-api
```

## Image vs. container

- **Image** — the recipe. Built once, immutable.
- **Container** — a running instance. Disposable, ephemeral.
