## What and why

Code ships. Feature stays off until you flip a flag. Benefits:

- **Kill switch** — instantly disable a buggy feature without redeploying.
- **Gradual rollout** — 1%, 10%, 50%, 100% of users.
- **A/B test** — assign variants by user hash.
- **Per-user override** — turn on for QA / specific customers.
- **Trunk-based dev** — merge incomplete features behind flags.

## Code shape

```ts
if (await flags.isEnabled('new-checkout', { userId })) {
  return newCheckout();
} else {
  return oldCheckout();
}
```

## Tools

- **LaunchDarkly** — full-featured, enterprise.
- **GrowthBook** — open source, self-hostable.
- **Unleash** — open source.
- **Vercel Edge Config / Cloudflare KV** — DIY for simple cases.
- **A row in Postgres** — fine for small teams.

## Anti-patterns

- **Stale flags** that nobody removes. Audit and clean up.
- **Flags as long-term config.** Use env vars or settings instead.
- **Cascading flags** (flag A depends on flag B depends on...). Hard to reason about.
