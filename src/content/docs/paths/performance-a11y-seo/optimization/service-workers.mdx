## HTTP caching

Set the right headers and the browser caches assets for free:

```http
Cache-Control: public, max-age=31536000, immutable
```

For HTML you re-deploy often:

```http
Cache-Control: public, max-age=0, must-revalidate
ETag: "abc123"
```

Browser sends `If-None-Match`; server returns `304 Not Modified` if unchanged.

## Service Workers

A script that intercepts every network request from the page. Lets you:

- Serve cached assets when offline.
- Pre-cache critical resources at install.
- Update assets in the background.

Use **Workbox** (or Vite's `@vite-pwa/astro`) — don't write SW code by hand:

```js
// Auto-cache all build assets, serve them stale-while-revalidate
registerSW({ runtimeCaching: [{ urlPattern: /\.(js|css)$/, handler: 'StaleWhileRevalidate' }] });
```

## Cache invalidation

Hash file names. `app.abc123.js` is fine to cache forever — when content changes, the file name changes too.

HTML and JSON: short cache, ETag-driven.
