## The four behaviors

- **`font-display: auto`** — browser default; usually FOIT (text invisible briefly).
- **`font-display: swap`** — show fallback immediately, swap when loaded. FOUT.
- **`font-display: optional`** — try briefly; if not loaded fast enough, never use the custom font this session. Best for CWV but visually inconsistent.
- **`font-display: fallback`** — middle ground.

## Recommended setup

```css
@font-face {
  font-family: 'Inter';
  src: url('/fonts/Inter.woff2') format('woff2');
  font-weight: 400 700;
  font-display: swap;
  /* Match the fallback's metrics to reduce visible shift on swap */
  size-adjust: 105%;
  ascent-override: 90%;
}
```

## Preload the LCP font

```html
<link rel="preload" as="font" type="font/woff2" href="/fonts/Inter.woff2" crossorigin>
```

`crossorigin` is required even for same-origin fonts.

## Subset

Strip glyphs you don't use. `glyphhanger` and Google's `&text=` parameter help.
