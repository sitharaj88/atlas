## Use modern formats

- **AVIF** — smallest, broadest modern support.
- **WebP** — good fallback, near-universal.
- **JPEG** — last resort.
- **PNG** — only for transparency or pixel-art.

## Serve responsively

```html
<picture>
  <source type="image/avif" srcset="hero.avif">
  <source type="image/webp" srcset="hero.webp">
  <img src="hero.jpg" srcset="hero-400.jpg 400w, hero-800.jpg 800w" sizes="50vw"
       width="800" height="600" alt="..." fetchpriority="high">
</picture>
```

## Lazy load below the fold

```html
<img src="..." loading="lazy" decoding="async" alt="...">
```

NOT on the LCP image.

## Build pipeline

- **Astro / Next** have built-in image optimization (`<Image>`).
- **sharp** (Node) for build-time resizing.
- **Cloudflare Images / Imgix / Cloudinary** for on-the-fly transformation.

A `2000×1200` photo served at full size when displayed at `400×240` is 25× wasted. Optimization is the easiest perf win.
