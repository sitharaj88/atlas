## Where to split

- **By route.** Each page loads its own chunk.
- **By heavy widget.** A rich text editor or chart library, lazy-loaded on demand.

## Dynamic import

```ts
button.addEventListener('click', async () => {
  const { Editor } = await import('./Editor.tsx');
  open(<Editor />);
});
```

Bundlers split at every `import()` automatically.

## Prefetch hints

```html
<!-- The user's about to need it; download with low priority -->
<link rel="prefetch" href="/_astro/editor.abc.js">
```

```jsx
// In React Router / Next, hover-to-prefetch is built-in
<Link to="/dashboard" prefetch="intent">Dashboard</Link>
```

## Tree-shake hard

- Avoid barrel files (`export * from`) on hot paths.
- Use ES modules.
- Verify with `vite-plugin-visualizer` or `bundle-buddy`.
