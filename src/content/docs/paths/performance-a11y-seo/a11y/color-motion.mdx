## Contrast targets (WCAG 2.2 AA)

- **Normal text** — 4.5:1
- **Large text** (≥18.66px bold or ≥24px) — 3:1
- **Non-text UI** — 3:1

Tools: DevTools color picker, WebAIM Contrast Checker, axe.

## Don't rely on color alone

Pair red errors with an icon, label, or aria-live region. ~8% of men are red/green color-blind.

## Reduced motion

```css
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: 0.01ms !important;
    transition-duration: 0.01ms !important;
  }
}
```

## Don'ts

- Auto-playing video on load.
- Heavy parallax.
- Flashing > 3 Hz (epilepsy risk).
