## Visible focus is non-negotiable

```css
:focus-visible {
  outline: 3px solid var(--brand);
  outline-offset: 2px;
}
```

Never `:focus { outline: none; }` without a replacement.

## Manage focus when DOM changes

Open a modal? Focus the first interactive element inside. Close it? Restore to the trigger.

```js
function openDialog(triggerEl) {
  dialog.showModal();
  dialog.querySelector('h2').focus();
  trigger = triggerEl;
}
function closeDialog() {
  dialog.close();
  trigger?.focus();
}
```

The `<dialog>` element traps focus and handles Esc automatically.

## Skip-to-main

Long header → keyboard users want to skip:

```html
<a class="skip-link" href="#main">Skip to main content</a>
<main id="main" tabindex="-1">...</main>
```

Show on focus, hide otherwise.
