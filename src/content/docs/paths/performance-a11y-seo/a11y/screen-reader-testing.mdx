## Three screen readers worth knowing

- **VoiceOver** — built into macOS (Cmd+F5) and iOS (triple-click home).
- **NVDA** — free for Windows.
- **TalkBack** — built into Android.

## A 5-minute test

1. Cmd+F5. **Tab through your page.** Each control should announce a clear name and role.
2. **VO+H** — list headings. Are they ordered? Make sense?
3. **VO+L** — list links. Are they descriptive?
4. **Submit a form** with errors. Does VO announce them?
5. **Open a modal.** Does focus move?

You'll find 5 issues in 5 minutes on a fresh codebase. That's normal.

## Common fails

- Buttons named "click here."
- Empty buttons (icon only, no aria-label).
- Modal opens but focus stays on the trigger button.
- Toasts appear with no `aria-live`.
