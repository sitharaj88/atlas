## The rule

Pick the element that **means** what you intend:

- Click triggers an action → `<button>`
- Click navigates → `<a href>`
- Form group → `<form>` + `<fieldset>` + `<label>`
- Sections → `<header>`, `<main>`, `<nav>`, `<aside>`, `<footer>`
- Disclosure → `<details>` + `<summary>`
- Modal → `<dialog>`

`<div onclick>` is always wrong unless you've also added: focusable (`tabindex`), keyboard activation (Space+Enter), role (`role="button"`), and accessible name (`aria-label`). At which point — just use `<button>`.
