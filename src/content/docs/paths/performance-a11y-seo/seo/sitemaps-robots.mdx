## sitemap.xml

A list of URLs you want crawled. Reference it from robots.txt and submit in Search Console.

```xml
<?xml version="1.0" encoding="UTF-8"?>
<urlset xmlns="http://www.sitemaps.org/schemas/sitemap/0.9">
  <url><loc>https://atlas.dev/</loc></url>
  <url><loc>https://atlas.dev/paths/foundations/</loc></url>
</urlset>
```

Most frameworks (Astro, Next, Nuxt) generate this for you.

## robots.txt

Allow/disallow crawl paths:

```text
User-agent: *
Allow: /
Disallow: /admin/

Sitemap: https://atlas.dev/sitemap.xml
```

Use sparingly. `Disallow` is a request, not enforcement.

## Canonical URLs

When the same content is reachable via multiple URLs, declare the canonical:

```html
<link rel="canonical" href="https://atlas.dev/paths/foundations/">
```

Prevents duplicate-content penalties. Critical when query strings or trailing slashes vary.
