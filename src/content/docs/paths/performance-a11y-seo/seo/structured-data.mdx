## What it is

JSON in a `<script>` tag describing the page using a vocabulary (schema.org):

```html
<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "Article",
  "headline": "How the web works",
  "author": { "@type": "Person", "name": "Atlas" },
  "datePublished": "2026-05-08",
  "image": "https://atlas.dev/og.png"
}
</script>
```

Google parses this and may show rich snippets (article previews, FAQs, recipes, etc.).

## Common types

- **Article / BlogPosting** — articles.
- **Product** — e-commerce.
- **FAQPage** — Q&A sections.
- **HowTo** — tutorials.
- **Organization / Person** — entity pages.
- **BreadcrumbList** — show breadcrumbs in results.

## Validate

Use Google's [Rich Results Test](https://search.google.com/test/rich-results) before shipping.
