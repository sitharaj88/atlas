## The tags

```html
<meta property="og:title" content="How the web works — Atlas">
<meta property="og:description" content="A clear mental model from URL to pixels.">
<meta property="og:image" content="https://atlas.dev/og/foundations.png">
<meta property="og:image:width" content="1200">
<meta property="og:image:height" content="630">
<meta property="og:type" content="article">
<meta property="og:url" content="https://atlas.dev/paths/foundations/">

<meta name="twitter:card" content="summary_large_image">
```

## Image specs

- **1200 × 630** is the safe size — Twitter, Slack, Facebook, LinkedIn all show it well.
- Under 1MB. PNG or JPEG.
- Text large enough to read at 600×315 (the smallest preview size).

## Generate per page

Most frameworks support generating OG images per page:

- **Astro** — `astro-og-canvas`.
- **Next.js** — `next/og` ImageResponse API.
- **Vercel OG** — popular helper.

Atlas itself generates one per route automatically.
