## Title

Unique per page. Under ~60 chars (else truncated in search results). Include the topic and brand:

```html
<title>How the web works — Atlas</title>
```

## Meta description

Not a ranking factor, but the snippet shown in results. ~150 chars. Compelling, accurate, not stuffed.

```html
<meta name="description" content="A clear mental model — from typing a URL to seeing pixels. HTTP, DNS, browsers, the rendering pipeline.">
```

## Heading hierarchy

- One `<h1>` per page — the topic.
- `<h2>` for top-level sections.
- `<h3>` for subsections.
- Don't skip levels.

Search engines use heading order to understand structure. Screen readers use it for navigation.

## URL slugs

- Lowercase, hyphenated.
- Descriptive. `/posts/how-the-web-works` beats `/posts/12345`.
- Stable. Once published, don't change without a redirect.
