## The pipeline, with timing

```text
HTML bytes ──► Parse → DOM
CSS bytes  ──► Parse → CSSOM
                       │
                       ▼
                   Render tree
                       │
                       ▼
                    Layout       ← reflow
                       │
                       ▼
                    Paint        ← repaint
                       │
                       ▼
                  Composite      ← cheap
```

## What changes what

| Change | Triggers |
|---|---|
| `width`, `top`, `font-size`, DOM insertion | Layout → Paint → Composite |
| `background-color`, `color`, `box-shadow` | Paint → Composite |
| `transform`, `opacity` | Composite only |

Animate `transform` and `opacity`. Avoid layout-triggering changes in animations.

## DevTools timeline

DevTools → Performance tab → Record. The "Main" track shows tasks. Look for:

- **Long Tasks** (over 50ms) — block input, hurt INP.
- **Forced reflows** — yellow warnings; reading layout after writing it.
- **Heavy paint** — large repainted regions on scroll.
