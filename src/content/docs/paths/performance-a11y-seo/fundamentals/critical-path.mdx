## What blocks first paint

- **HTML** itself (it's the entry).
- **`<link rel="stylesheet">`** in `<head>` (render-blocking by default).
- **Synchronous `<script>`** in `<head>` (parser-blocking AND render-blocking).
- **Web fonts** (text waits unless `font-display: swap`).

## The fastest LCP recipe

```html
<!-- Inline critical CSS -->
<style>/* above-the-fold */</style>

<!-- Defer non-critical CSS -->
<link rel="stylesheet" href="/main.css" media="print" onload="this.media='all'">

<!-- Preload the LCP image -->
<link rel="preload" as="image" href="/hero.avif" fetchpriority="high">

<!-- Defer JS -->
<script src="/app.js" defer></script>

<!-- Font that doesn't block text -->
<style>@font-face { font-display: swap; }</style>
```

## What does NOT block

- `<script defer>` and `<script async>` — start fetch but don't pause parsing.
- Images and videos (the parser keeps going).
- CSS in `<body>` (loads but is non-blocking… mostly).
