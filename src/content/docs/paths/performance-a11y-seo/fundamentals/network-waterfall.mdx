## Reading the bars

Each row's bar shows phases:

```
Queue → Stalled → DNS → TCP → TLS → Wait (TTFB) → Download
```

- **Long Wait** = server slow.
- **Long Stalled** = too many requests on one connection (HTTP/1.1) or browser priority pushed it back.
- **Long DNS / TCP / TLS** = first connection to a host (subsequent reuse is free).

## Patterns of waste

- **Render-blocking CSS deep in the waterfall.** Means HTML had inline `<link>` further down. Move to head OR inline.
- **Sequential dependent fetches.** `app.js` waits for HTML, JSON waits for `app.js`, image waits for JSON. Three round-trips. Hint with `<link rel="preload">` to start fetches earlier.
- **Render-blocking 3rd party scripts.** Tag managers, analytics. Defer or load async.
- **Many small assets.** With HTTP/2, less of an issue, but bundling still helps.

## Quick wins

- **`<link rel="preconnect">`** for third-party origins you'll fetch from.
- **`<link rel="preload" as="font">`** for the LCP web font.
- **Resource hints in HTML head**, not added later via JS.
