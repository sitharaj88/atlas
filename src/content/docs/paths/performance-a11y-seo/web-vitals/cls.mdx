## What it measures

Sum of unexpected layout shifts during page life. Goal: ≤ 0.1 at the 75th percentile.

## Common causes

- Images without `width`/`height`.
- Embeds (YouTube, ads) loading after content.
- Web fonts swapping in with very different metrics.
- Banners pushed in by JS late.

## Fixes

```html
<!-- 1. Images: always width + height (or aspect-ratio) -->
<img src="..." width="1200" height="675" alt="...">

<!-- 2. Reserve space for embeds -->
<div style="aspect-ratio: 16 / 9; background: #f0f0f0;">
  <iframe src="..." />
</div>

<!-- 3. Match font metrics -->
@font-face { src: url(...); size-adjust: 105%; ascent-override: 90%; }

<!-- 4. Animate with transform, not top/left -->
.menu { transform: translateX(-100%); transition: transform 200ms; }
```
