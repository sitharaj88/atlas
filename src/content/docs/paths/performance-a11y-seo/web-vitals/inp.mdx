## What it measures

Time from a user input (click, tap, key) to the next paint that reflects it. Reported INP is the **slowest** of all interactions in a session (one outlier per 50). Goal: ≤ 200ms at the 75th percentile.

## Common causes

- Long JS tasks blocking the main thread.
- Big React re-renders on every keystroke.
- Layout thrashing inside event handlers.
- Synchronous calls to slow APIs from a click handler.

## Fixes

**Yield to the browser:**

```js
async function processItems(items) {
  for (let i = 0; i < items.length; i++) {
    process(items[i]);
    if (i % 100 === 0) await new Promise(r => setTimeout(r));
  }
}
```

**Defer non-urgent updates (React):**

```jsx
const [input, setInput] = useState('');
const deferredInput = useDeferredValue(input);
return (
  <>
    <input value={input} onChange={e => setInput(e.target.value)} />
    <ExpensiveResults query={deferredInput} />
  </>
);
```

**Don't read layout in handlers** (`offsetWidth`, `getBoundingClientRect`) — causes synchronous reflow.
