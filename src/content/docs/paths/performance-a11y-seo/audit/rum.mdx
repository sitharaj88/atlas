## The web-vitals library

```ts
import { onLCP, onINP, onCLS, onFCP, onTTFB } from 'web-vitals';

function send(metric) {
  navigator.sendBeacon('/rum', JSON.stringify(metric));
}

onLCP(send); onINP(send); onCLS(send); onFCP(send); onTTFB(send);
```

`web-vitals` library handles the timing nuances. You ship the numbers to your analytics.

## Where to send

- **Sentry, Datadog, New Relic** — integrated with their products.
- **Cloudflare Web Analytics** — free, anonymized, drop-in.
- **Vercel Speed Insights** — built-in if you deploy there.
- **Self-hosted** — Plausible, Umami, your own DB.

## Slice by

- **Country / device class.** Field perf varies wildly.
- **Page type.** Home vs. product page.
- **Build version.** "Did my last deploy regress LCP?"
