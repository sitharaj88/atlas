## Lighthouse

Built into Chrome DevTools. Single-run lab measurement of performance, a11y, SEO, best practices. Good for quick checks while developing.

## WebPageTest

Multiple runs. Real devices. Filmstrip + waterfall. Best for deep performance investigations.

## PageSpeed Insights

Combines Lighthouse (lab) + CrUX (field data from real Chrome users). The real number Google uses for ranking.

## Lab vs. field

Lab numbers come from one machine, one configuration. Field data is what real users experience. **Always validate with field data** before declaring victory — a green Lighthouse with a red CrUX field report means real users are still slow.
