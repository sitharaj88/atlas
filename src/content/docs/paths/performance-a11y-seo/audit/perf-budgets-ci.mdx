## Pick budgets

Concrete numbers your team commits to:

- **JS bundle: < 100 KB gzip** for the home page.
- **LCP: < 2.5s** at p75.
- **CLS: < 0.1** at p75.
- **Image bytes: < 500 KB** per page.

## Enforce in CI

**Lighthouse CI:**

```yaml
- run: pnpm dlx @lhci/cli autorun --collect.url=http://localhost:4321
```

Configure budgets in `lighthouserc.json`:

```json
{
  "ci": {
    "assert": {
      "assertions": {
        "categories:performance": ["error", { "minScore": 0.9 }],
        "first-contentful-paint": ["error", { "maxNumericValue": 1500 }]
      }
    }
  }
}
```

**Bundle size:**

```yaml
- uses: pkg-size/pkg-size-action@v1
```

Or `size-limit` for stricter per-export limits.

**Visual regression** with Playwright + screenshot diffs catches CLS issues that perf scores miss.
