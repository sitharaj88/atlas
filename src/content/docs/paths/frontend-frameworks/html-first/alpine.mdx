## The pitch

```html
<div x-data="{ open: false }">
  <button @click="open = !open">Toggle</button>
  <div x-show="open">Hello</div>
</div>
```

15 KB minified. Reactivity inline in HTML. No build step required.

## Common directives

- `x-data` — local state.
- `x-show` / `x-if` — conditional render.
- `x-for` — loops.
- `x-on:click` (or `@click`) — events.
- `x-model` — two-way binding.
- `x-bind:class` (or `:class`) — dynamic attrs.

## When Alpine

- Server-rendered pages with small interactive bits.
- You want a sprinkle of JS, not a framework.
- Pairs nicely with HTMX.
