## The pitch

```html
<button hx-post="/clicked" hx-swap="outerHTML">Click me</button>
```

Click → POST /clicked → server returns HTML → HTMX swaps it in. No JSON, no client-side state, no framework.

## When HTMX wins

- Server-rendered apps (Rails, Django, Laravel, Phoenix, Spring).
- Small interactive surfaces.
- Teams allergic to SPA complexity.
- Forms, search, dynamic dropdowns, infinite scroll.

## When it loses

- Highly interactive client apps (editors, dashboards).
- Real-time / collaborative features.
- Offline-first.
- When your team is React-shop and the win doesn't justify the second pattern.

## A real interaction

```html
<input hx-get="/search" hx-trigger="keyup changed delay:300ms" hx-target="#results">
<ul id="results"></ul>
```

Type → debounced 300ms → GET /search → HTML inserted into #results. About 5 lines that would be 50 in React.
