## Native custom elements

```js
class MyButton extends HTMLElement {
  connectedCallback() {
    this.innerHTML = `<button>${this.textContent}</button>`;
  }
}
customElements.define('my-button', MyButton);
```

Now `<my-button>Save</my-button>` works in any page, framework or not.

## Lit

```ts
import { LitElement, html, css } from 'lit';

class MyButton extends LitElement {
  static styles = css`button { background: navy; color: white; }`;
  static properties = { label: { type: String } };
  render() { return html`<button>${this.label}</button>`; }
}
customElements.define('my-button', MyButton);
```

Lit adds reactivity, declarative templates, and tiny size (~5 KB).

## When web components shine

- **Shared components across frameworks** — design systems consumed by React, Vue, Svelte all at once.
- **Long-lived microfrontends** — frameworks change; web components persist.
- **Browser extensions and embeds** — drop into any page.

## Limitations

- Shadow DOM CSS isolation is great… until you need to style across boundaries.
- SSR is harder (declarative shadow DOM is the answer; tooling is catching up).
- Slightly more boilerplate than React/Vue/Svelte.
