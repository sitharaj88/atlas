## The pitch

Remix (now React Router 7) treats the browser like the web platform it is. Forms post HTTP. Loaders run on the server, return data. Actions handle mutations. Everything is `Request` and `Response`.

```tsx
// loaders run on the server, return data to the component
export async function loader({ params }) {
  return { post: await db.post.find(params.id) };
}

export default function Post() {
  const { post } = useLoaderData<typeof loader>();
  return <article>{post.body}</article>;
}

// actions handle mutations from <Form>
export async function action({ request }) {
  const data = await request.formData();
  await db.post.update(/* ... */);
  return redirect('/posts');
}
```

No client-side fetch library, no global state for server data. The browser can submit forms even without JS.

## When to pick

- Web-platform-first culture.
- Heavy form/mutation workflows.
- You like progressive enhancement.
- You want to deploy anywhere with a Web-Fetch-compatible runtime (Cloudflare, Deno, Node).
