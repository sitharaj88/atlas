## The pitch

A full-stack React framework built on TanStack Router. Strong type-safety from URL → loader → page → params. Pairs with TanStack Query for server state.

```tsx
const route = createFileRoute('/posts/$id')({
  loader: async ({ params }) => fetchPost(params.id),
  component: Post,
});

function Post() {
  const post = Route.useLoaderData();   // fully typed
  return <article>{post.body}</article>;
}
```

## When to pick

- You love TanStack Query and want one-stack consistency.
- You want type-safe routing without code generation.
- You don't want to be tied to Vercel-flavored opinions.

## Status

Newer than Next/Remix; ecosystem smaller. For greenfield projects with a TS-first team, increasingly compelling.
