## A component

```vue
<script setup lang="ts">
import { ref, computed } from 'vue';

const count = ref(0);
const doubled = computed(() => count.value * 2);
function inc() { count.value++; }
</script>

<template>
  <button @click="inc">{{ count }} (doubled: {{ doubled }})</button>
</template>
```

`<script setup>` runs once per component instance. Anything top-level is in the template's scope. No `data()`/`methods()`/`computed: {}` boilerplate.

## Three core primitives

- **`ref(v)`** — reactive value. Read/write `.value` in JS; auto-unwrapped in templates.
- **`reactive(obj)`** — reactive object. Use for complex state shapes.
- **`computed(fn)`** — derived reactive value. Cached, recomputed when deps change.

## Composables

```ts
// useCounter.ts
import { ref } from 'vue';
export function useCounter() {
  const count = ref(0);
  return { count, inc: () => count.value++ };
}
```

Plain JS that returns reactive state. Vue's analog of React custom hooks.
