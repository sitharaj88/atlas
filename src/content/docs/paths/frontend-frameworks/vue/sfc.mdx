## Three blocks

```vue
<script setup lang="ts">
const name = 'Atlas';
</script>

<template>
  <h1 class="title">{{ name }}</h1>
</template>

<style scoped>
.title { font-size: 2rem; color: navy; }
</style>
```

- `<script setup>` — JS/TS, the component logic.
- `<template>` — HTML with `{{ }}` interpolation and `v-` directives.
- `<style scoped>` — CSS, scoped to this component (auto-namespaced).

`<style>` without `scoped` is global. Reach for that for design tokens or resets.

## Directives

```vue
<button v-on:click="inc">+</button>     <!-- @click is shorthand -->
<input v-model="name">                  <!-- two-way binding -->
<div v-if="loggedIn">...</div>          <!-- conditional render -->
<li v-for="item in items" :key="item.id">{{ item.name }}</li>
<div :class="{ active: isActive }">     <!-- :prop is v-bind:prop -->
```

## When SFCs win

- Co-located styles with scoped CSS.
- One file = one component, easy to navigate.
- Tooling (volar) understands the cross-block scope.
