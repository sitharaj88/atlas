## ref vs reactive

```ts
const count = ref(0);
count.value++;          // ✓

const state = reactive({ count: 0 });
state.count++;           // ✓ no `.value`
```

Reach for `ref` for primitives (numbers, strings, booleans). Use `reactive` for object shapes when you don't want `.value` everywhere.

## watch and watchEffect

```ts
watch(count, (newVal, oldVal) => console.log(newVal));

watchEffect(() => {
  console.log(`count is ${count.value}`);  // re-runs when count changes
});
```

`watch` is explicit (you list the source). `watchEffect` auto-tracks (any reactive read inside the function becomes a dep).

## When the reactivity "doesn't work"

- **Destructuring** a `reactive` object loses reactivity. Use `toRefs` to keep refs.
- **Replacing** a reactive value (`state = newState`) breaks tracking. Mutate properties instead.
