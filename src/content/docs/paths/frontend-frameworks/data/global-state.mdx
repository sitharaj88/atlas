## The hierarchy

1. **`useState`** + composition — try this first.
2. **Context** — for app-wide values that rarely change (theme, locale, current user).
3. **Zustand / Jotai / Valtio** — small, hooks-friendly. State outside React, slot in by hook.
4. **Redux Toolkit** — when you need time-travel debugging, middleware, plugins.

In 2026 most apps are at 1 + 3. Redux is great for huge, complex apps that benefit from its tooling.

## Zustand example

```js
import { create } from 'zustand';
const useStore = create((set) => ({
  count: 0,
  inc: () => set((s) => ({ count: s.count + 1 })),
}));

function Counter() {
  const { count, inc } = useStore();
  return <button onClick={inc}>{count}</button>;
}
```

Lightweight, no boilerplate, no Provider needed.
