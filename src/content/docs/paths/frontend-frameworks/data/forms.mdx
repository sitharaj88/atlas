## React Hook Form (RHF)

Uncontrolled by default. Best for big complex forms with conditional fields:

```jsx
const { register, handleSubmit, formState: { errors } } = useForm();
return (
  <form onSubmit={handleSubmit(onSubmit)}>
    <input {...register('email', { required: true })} />
    {errors.email && <span>required</span>}
  </form>
);
```

## Conform

Newer, server-action-friendly, progressive-enhancement-first. Pairs with Zod for validation. Best fit for Remix/Next App Router.

## Native HTML form (with React 19)

For simple forms, just use `<form>` with React 19's `<form action>`:

```jsx
async function action(formData) {
  'use server';
  await save(formData.get('email'));
}
return <form action={action}><input name="email" /><button>Save</button></form>;
```

Server Actions handle submission. No client-side state needed.

## Pick by complexity

- Trivial form (1–3 fields, no validation) → native.
- Complex form (multi-step, conditional, dynamic) → RHF or Conform.
- Server-driven app → Conform or native form actions.
