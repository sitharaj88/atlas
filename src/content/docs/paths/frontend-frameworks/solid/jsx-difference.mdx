## Same look, different rules

```jsx
// React
function List({ items }) {
  return <ul>{items.map(i => <li>{i.name}</li>)}</ul>;
}

// Solid
import { For } from 'solid-js';
function List(props) {
  return <ul><For each={props.items}>{(i) => <li>{i.name}</li>}</For></ul>;
}
```

In Solid:
- **Use `<For>`** instead of `.map()` for lists. The compiler optimizes it.
- **`props.items`** — never destructure props. Destructuring would unwrap the reactivity.
- **Components run once.** No `useEffect` for re-runs; use `createEffect`.

## Mental shift

In React, "render" runs the component function every time state changes. In Solid, the component function runs once; *expressions* re-run.

Once you internalize that, signals make perfect sense.
