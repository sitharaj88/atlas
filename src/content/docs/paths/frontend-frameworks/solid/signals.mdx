## A component

```jsx
import { createSignal, createMemo } from 'solid-js';

function Counter() {
  const [count, setCount] = createSignal(0);
  const doubled = createMemo(() => count() * 2);
  return (
    <button onClick={() => setCount(count() + 1)}>
      {count()} (doubled: {doubled()})
    </button>
  );
}
```

## The big difference

Solid components run **once**. The framework tracks every signal access. When a signal changes, only the precise DOM expressions that depend on it re-execute. Not the component, not the JSX — just the `{count()}` text node.

Result: extreme performance with React-like ergonomics.

## When Solid

- You want React's mental model with much less re-rendering.
- Performance-critical UI.
- You're starting fresh.

## When not Solid

- You need React's ecosystem of libraries.
- Hiring developers familiar with the stack.
