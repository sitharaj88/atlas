## What the compiler does

Svelte transforms `.svelte` files into vanilla JS that directly manipulates the DOM. No virtual DOM, no diff. The output is small and fast.

## Trade-offs

**Pros:**
- Smaller bundles than runtime-heavy frameworks.
- Faster initial render.
- Less abstraction in DevTools — you see the actual DOM updates.

**Cons:**
- Harder to introspect at runtime (no component tree to walk via JS).
- Some patterns (deeply dynamic component composition) are awkward.
- Smaller ecosystem than React.

## When Svelte wins

- Performance-sensitive apps.
- Small teams who like reading clear, top-down code.
- Sites where bundle size really matters.
