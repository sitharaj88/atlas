## Shape

```
src/routes/
├── +page.svelte           # / (component)
├── +page.server.ts        # / loader (server only)
├── posts/
│   ├── +page.svelte
│   └── [id]/
│       ├── +page.svelte
│       └── +page.server.ts
└── api/
    └── +server.ts         # /api endpoint
```

`+page.svelte` is the page. `+page.server.ts` runs server-only logic (loaders, actions). `+server.ts` is an HTTP endpoint.

## Loaders

```ts
// +page.server.ts
export async function load({ params }) {
  return { post: await db.post.find(params.id) };
}
```

```svelte
<!-- +page.svelte -->
<script>
  export let data;
</script>
<h1>{data.post.title}</h1>
```

## Form actions

```ts
export const actions = {
  default: async ({ request }) => {
    const data = await request.formData();
    await save(data);
    return { success: true };
  },
};
```

Server-side form handling, progressive-enhancement friendly.
