## A component

```svelte
<script>
  let count = $state(0);
  let doubled = $derived(count * 2);
  $effect(() => console.log('count:', count));
</script>

<button onclick={() => count++}>{count} (doubled: {doubled})</button>
```

- **`$state`** — reactive value.
- **`$derived`** — computed. Auto-tracks deps.
- **`$effect`** — side effect that re-runs when its deps change.
- **`$props`** — declare component props.

## Why runes (vs. Svelte 4)

Svelte 4 used compiler magic — top-level `let` was reactive, plain assignment in scripts triggered updates. Powerful but surprising. Runes make reactivity explicit; type-checking and AST tooling work better.
