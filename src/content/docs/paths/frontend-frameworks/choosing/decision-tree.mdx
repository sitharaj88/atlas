## The tree

```text
Is the project mostly content (blog, docs, marketing)?
  → Astro

Is it server-rendered (Rails/Django/Laravel) with sprinkles of JS?
  → HTMX + Alpine

Is the team React-shop?
  → Next.js (full-stack) or Remix/RR7 (web-platform first)

Is it a SPA dashboard / editor / IDE?
  → Solid (perf) or React + TanStack Start (TS-first)

Is the team Vue-shop?
  → Nuxt

Is the team Svelte-curious?
  → SvelteKit

Will the components ship across teams/frameworks?
  → Lit / Web Components
```

## Don't overthink it

Most teams ship fine on any of these. The wrong "framework choice" is rarely what kills a project. Skill, design, deploy reliability, and product clarity matter more.
