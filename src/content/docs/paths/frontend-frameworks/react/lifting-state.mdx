## Lifting state up

When two siblings need the same data, move state to their **lowest common ancestor**:

```jsx
function App() {
  const [filter, setFilter] = useState('');
  return (
    <>
      <SearchBar value={filter} onChange={setFilter} />
      <Results filter={filter} />
    </>
  );
}
```

## Prop drilling

When state lives several levels above where it's needed, you pass it down through every level:

```
App → Page → Toolbar → Search
```

For 1-2 levels, fine. Beyond that, reach for **Context**, a state library (Zustand/Jotai), or composition.

## Composition over passing

Often the cleaner answer is to pass children:

```jsx
<Page>
  <Toolbar><Search /></Toolbar>  {/* Search receives state directly */}
</Page>
```

The "lifted" component renders the inner one with its own props/state — no drilling needed.
