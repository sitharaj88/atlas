## The transformation

```jsx
const ui = <h1 className="title">Hello, {name}</h1>;
```

Compiles to:

```js
const ui = jsx('h1', { className: 'title', children: ['Hello, ', name] });
```

`jsx()` returns a plain JS object (a "React element" — a description of UI). React renders elements into real DOM.

## Implications

- **JSX is JS.** You can put any JS expression in `{}`.
- **Children are just data.** `<Foo>` followed by `</Foo>` becomes `Foo({ children: ... })`.
- **`className` not `class`** — `class` is a JS reserved word. Same for `htmlFor` not `for`.
- **Attributes are camelCase.** `tabIndex`, `onClick`, `ariaLabel`.

## Conditionals and lists

```jsx
{isLoggedIn && <Logout />}
{user ? <Hello /> : <SignIn />}
{items.map(i => <Item key={i.id} {...i} />)}
```

Just JS expressions. No special syntax.
