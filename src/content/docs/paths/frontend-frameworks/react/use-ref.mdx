## Two uses of useRef

**1. DOM access:**

```jsx
const inputRef = useRef(null);
useEffect(() => inputRef.current?.focus(), []);
return <input ref={inputRef} />;
```

**2. Mutable instance values that don't trigger re-renders:**

```jsx
const id = useRef(0);
function next() { return ++id.current; }
```

Updates to `ref.current` don't cause renders. Useful for IDs, timers, previous values.

## Forwarding refs

```jsx
const TextField = forwardRef((props, ref) => <input ref={ref} {...props} />);
```

In React 19, this changes — refs are passed as a regular prop, no `forwardRef` wrapper needed.

## When NOT to reach for refs

- To "force a render" — use state.
- To skip controlled inputs — usually a smell.
- To work around a re-render issue — find the root cause first.
