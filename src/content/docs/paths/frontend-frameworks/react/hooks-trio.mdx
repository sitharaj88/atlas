## useState

```jsx
const [count, setCount] = useState(0);
setCount(count + 1);
setCount(c => c + 1);    // updater function — safer when you depend on prev state
```

State persists across re-renders. Updates are queued until the next render.

## useEffect

```jsx
useEffect(() => {
  const id = setInterval(tick, 1000);
  return () => clearInterval(id); // cleanup
}, [/* deps */]);
```

Runs after render. The deps array decides when:
- `[]` — once after mount.
- `[a, b]` — when a or b changed.
- omitted — every render.

Cleanup runs before the next effect AND on unmount.

## useReducer

```jsx
const [state, dispatch] = useReducer(reducer, initial);
function reducer(s, action) {
  switch (action.type) {
    case 'inc': return { count: s.count + 1 };
    case 'reset': return initial;
  }
}
dispatch({ type: 'inc' });
```

Better than `useState` when state has multiple related fields or transitions are complex.

## Rules of hooks

- Call them at the **top level** of components/custom hooks (not inside conditions or loops).
- Call them only from **React functions** (components or other hooks).

The linter (`eslint-plugin-react-hooks`) catches violations.
