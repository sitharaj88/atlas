## When they help

- Expensive computation that runs on every render: `useMemo(() => sortBy(items, key), [items, key])`.
- A function passed to a memoized child: `useCallback(handle, [deps])`.

## When they don't

- Cheap computations. The bookkeeping costs more.
- Functions that aren't passed down. No referential equality needed.
- "Just in case" — premature optimization.

## React Compiler changes the math

React 19 ships an experimental compiler that auto-memoizes. With it on, you write plain code and the compiler decides what to memoize. Many `useMemo`/`useCallback` calls become unnecessary.

If you're not using the compiler, profile first, then memoize.
