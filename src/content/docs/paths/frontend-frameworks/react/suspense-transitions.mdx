## Suspense

```jsx
<Suspense fallback={<Spinner />}>
  <SlowComponent />
</Suspense>
```

A boundary that catches "I'm not ready" signals from descendants and shows the fallback instead. With RSC, with TanStack Query, with `use(promise)`, Suspense feels natural.

## Transitions

```jsx
const [isPending, startTransition] = useTransition();

function handleSearch(q) {
  setInput(q);                // urgent
  startTransition(() => {
    setQuery(q);              // non-urgent — UI can interrupt for typing
  });
}
```

Mark expensive state updates as non-urgent. React keeps the UI responsive; `isPending` lets you show subtle loading.

## useDeferredValue

```jsx
const deferred = useDeferredValue(query);
return <Results query={deferred} />;
```

Same idea, but for derived values. The component renders the **current** input fast, the slow result lags behind.

## When to reach for these

- Big lists that re-filter as you type → `useDeferredValue`.
- Routing transitions where the new page takes time to render → `startTransition`.
- Code-split components or async data → `Suspense`.
