## The three axes

- **Ergonomics** — how it feels to write code daily. (Svelte, Vue, Solid all win here for different reasons.)
- **Performance** — runtime speed, memory, bundle size. (Signal-based and compiled win.)
- **Ecosystem** — libraries, jobs, hires, learning material. (React leads by miles.)

## Which axis matters?

- **Solo project** — pick what you'll enjoy.
- **Startup hiring devs** — React. Largest pool.
- **Performance-critical (TVs, embedded)** — Solid, Lit, or vanilla.
- **Content sites** — Astro (islands).
- **Refactor-heavy team app** — TypeScript-friendly framework (React, Solid, Vue 3).

## Reality check

For 90% of web apps, **any modern framework is fine**. The bottleneck is rarely the framework — it's the developers' familiarity, the design system, the data layer, and the deploy pipeline.
