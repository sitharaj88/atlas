## Three strategies

**Virtual DOM (React)** — re-run components, diff the output trees, patch the real DOM. Mental model is simple; runtime cost is real.

**Fine-grained signals (Solid, Vue 3, Svelte 5)** — track which value each piece of UI depends on. Update only those pieces when a value changes. No diff, no re-render of unrelated components.

**Compilers (Svelte 4, Solid)** — at build time, analyze which DOM operations a component needs. Emit minimal imperative code. No runtime VDOM.

## Performance trade-offs

| Approach | Runtime cost | Bundle | Mental model |
|---|---|---|---|
| VDOM | Higher (diff each render) | Larger | Easy |
| Signals | Lower (granular) | Small | Medium |
| Compiled | Lowest | Smallest | Familiar (looks like JSX/HTML) |

For most apps, the difference is invisible. For massive lists or animation-heavy UIs, signals/compilers shine.
