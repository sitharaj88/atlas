## Three sources of types

1. **Bundled types** — most modern packages ship `.d.ts` files. Check `package.json`'s `types` or `typings` field.
2. **DefinitelyTyped** — `@types/<name>` packages for libraries without built-in types.
3. **Hand-written** — `*.d.ts` files for things without any of the above.

## Installing DefinitelyTyped

```bash
pnpm add -D @types/node @types/react @types/react-dom
```

These are community-maintained. Quality varies; usually fine for popular libs.

## Declaration merging

Add to an existing type, including library types:

```ts
// app.d.ts
declare global {
  interface Window {
    plausible?: (event: string) => void;
  }
}

window.plausible?.('signup'); // ✓ now typed
```

For module augmentation:

```ts
declare module 'react' {
  interface CSSProperties {
    '--brand'?: string; // allow custom CSS variables in style={{}}
  }
}
```

Useful for: extending `Window`, adding custom CSS variables to `style`, augmenting Express's `Request`.

## Ambient declarations

For files that have no types at all:

```ts
// images.d.ts
declare module '*.svg' {
  const src: string;
  export default src;
}
```

Tells TS that `import logo from './logo.svg'` returns a string.
