## The problem

```ts
function logId<T>(obj: T) {
  console.log(obj.id); // ✗ Property 'id' does not exist on type 'T'
}
```

T could be anything. The compiler refuses.

## The fix

```ts
function logId<T extends { id: string | number }>(obj: T) {
  console.log(obj.id);
  return obj;
}

const u = logId({ id: '42', name: 'Ada' });
//    type: { id: string; name: string }   ← T is preserved!
```

Constrain T to the minimum shape you need. You retain full T on the return — extra fields are kept.

## keyof in constraints

```ts
function get<T, K extends keyof T>(obj: T, key: K): T[K] {
  return obj[key];
}

const user = { id: 1, name: 'Ada' };
const name = get(user, 'name'); // type: string
const oops = get(user, 'foo');  // ✗ '"foo"' not assignable
```

`K extends keyof T` — K must be a key of T. `T[K]` is the type of the value at that key.

## Multiple constraints

```ts
function merge<A extends object, B extends object>(a: A, b: B): A & B {
  return { ...a, ...b };
}
```
