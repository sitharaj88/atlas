## Defaults

```ts
type ApiResponse<T = unknown> = { ok: boolean; data: T };

const r1: ApiResponse = { ok: true, data: 42 };       // T = unknown
const r2: ApiResponse<{ name: string }> = { ok: true, data: { name: 'a' } };
```

Same syntax as JS function defaults. Trailing arguments can be omitted.

## React's useState

```ts
function useState<T = undefined>(initial?: T): [T, (v: T) => void];

const [count, setCount] = useState(0);     // T = number
const [name, setName] = useState<string>(); // T = string (initial: undefined)
```

## Constraints + defaults

```ts
type ListBox<T extends string = 'general'> = {
  category: T;
  items: string[];
};
```

`T` must be a string; defaults to `'general'` if omitted.
