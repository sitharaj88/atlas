## The shape

```ts
function assert(condition: unknown, message: string): asserts condition {
  if (!condition) throw new Error(message);
}

function f(x: unknown) {
  assert(typeof x === 'string', 'expected string');
  x.toUpperCase(); // ✓ TS narrowed
}
```

Note: `asserts condition` (no `is`) just propagates a boolean check. Use `asserts x is T` to narrow the type:

```ts
function assertString(x: unknown): asserts x is string {
  if (typeof x !== 'string') throw new Error('not a string');
}
```

## When to reach for them

- Validating inputs at the top of a function.
- Custom invariants that can't be inferred.
- Migrating from `as` casts to safer code.
