## The shape

```ts
function isString(x: unknown): x is string {
  return typeof x === 'string';
}

function isUser(x: unknown): x is User {
  return typeof x === 'object' && x !== null && 'id' in x && 'name' in x;
}
```

The return type `x is T` tells TypeScript "if this returns true, treat x as T."

## Use it

```ts
function process(x: unknown) {
  if (isUser(x)) {
    x.name; // ✓ TS knows x is User
  }
}
```

## Asserting type guards

```ts
function assertString(x: unknown): asserts x is string {
  if (typeof x !== 'string') throw new Error('not a string');
}

function f(x: unknown) {
  assertString(x);
  x.toUpperCase(); // ✓ x is string from here on
}
```

`asserts x is T` — narrows AND throws if not. Useful for invariants.

## Validation libraries

In real apps, use **Zod** or **Valibot**:

```ts
import { z } from 'zod';
const User = z.object({ id: z.number(), name: z.string() });
type User = z.infer<typeof User>;

const u = User.parse(data); // throws if invalid; types inferred
```

The schema is the type. One source of truth for runtime + compile-time.
