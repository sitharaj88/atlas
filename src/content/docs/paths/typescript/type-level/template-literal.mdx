## Basics

```ts
type Greet<N extends string> = `Hello, ${N}!`;
type X = Greet<'Atlas'>; // "Hello, Atlas!"

type EventName<T extends string> = `on${Capitalize<T>}`;
type Y = EventName<'click'>; // "onClick"
```

## Built-in transforms

`Capitalize<S>`, `Uncapitalize<S>`, `Uppercase<S>`, `Lowercase<S>`.

## Distribute over unions

```ts
type Color = 'red' | 'green' | 'blue';
type ClassName = `text-${Color}`;
// "text-red" | "text-green" | "text-blue"
```

## Parsing strings (advanced)

```ts
type Split<S extends string, D extends string> =
  S extends `${infer Head}${D}${infer Tail}`
    ? [Head, ...Split<Tail, D>]
    : [S];

type Path = Split<'a/b/c', '/'>; // ['a', 'b', 'c']
```

This is the trick behind library types like `tRPC`'s path-based routing.
