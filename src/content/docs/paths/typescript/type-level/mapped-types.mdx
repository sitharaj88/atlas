## The basic shape

```ts
type Readonly<T> = {
  readonly [K in keyof T]: T[K];
};
```

For each key K in T, copy the field, mark it `readonly`.

## Built-ins

```ts
type Partial<T>    = { [K in keyof T]?: T[K] };
type Required<T>   = { [K in keyof T]-?: T[K] };       // -? removes optional
type Readonly<T>   = { readonly [K in keyof T]: T[K] };
type Pick<T, K extends keyof T> = { [P in K]: T[P] };
type Record<K extends keyof any, V> = { [P in K]: V };
```

`-?` and `-readonly` *remove* modifiers. Useful for "make all fields required":

```ts
type Strict<T> = { -readonly [K in keyof T]-?: T[K] };
```

## Key remapping

ES2022+ syntax — rename keys:

```ts
type Getters<T> = {
  [K in keyof T as `get${Capitalize<string & K>}`]: () => T[K];
};

type U = { name: string; age: number };
type G = Getters<U>; // { getName: () => string; getAge: () => number }
```

Combined with template literal types — extremely powerful.

## Filter keys

```ts
type StringKeys<T> = {
  [K in keyof T as T[K] extends string ? K : never]: T[K];
};

type U = { id: number; name: string; age: number };
type S = StringKeys<U>; // { name: string }
```

`as never` filters keys out of the resulting type.
