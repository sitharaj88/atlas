## Conditional types

```ts
type IsString<T> = T extends string ? true : false;

type A = IsString<'hello'>; // true
type B = IsString<42>;      // false
```

`T extends X ? Y : Z` — pick Y if T is assignable to X, else Z.

## Distributive

When T is a union, conditional types **distribute** over each member:

```ts
type ToArray<T> = T extends any ? T[] : never;
type X = ToArray<string | number>;   // string[] | number[]
```

To opt out, wrap in tuples: `[T] extends [X]`.

## infer

Extract a type from a position:

```ts
type ReturnType<F> = F extends (...args: any[]) => infer R ? R : never;

type Fn = () => string;
type R = ReturnType<Fn>; // string
```

`infer R` says "name this position R for the true branch."

## Common library types

```ts
type Awaited<T>     = T extends PromiseLike<infer U> ? Awaited<U> : T;
type Parameters<F>  = F extends (...args: infer P) => any ? P : never;
type ReturnType<F>  = F extends (...args: any) => infer R ? R : never;
type ConstructorReturn<C> = C extends abstract new (...args: any) => infer R ? R : never;
```

These ship in `lib.es5.d.ts`. Read them — that's how you learn the language.
