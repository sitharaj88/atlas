## Tuples

A tuple is an array with a fixed length and known types per position:

```ts
type Point = [number, number];
const p: Point = [3, 4];

type Entry = [key: string, value: number];   // labeled tuples
const e: Entry = ['x', 1];

type Variadic = [string, ...number[]];        // rest in tuples
```

`useState`'s `[value, setter]` is a labeled tuple under the hood.

## readonly

```ts
type FrozenList = readonly number[];
const f: FrozenList = [1, 2, 3];
f.push(4);           // ✗ Property 'push' does not exist on type 'readonly number[]'

interface User { readonly id: number; name: string; }
const u: User = { id: 1, name: 'Ada' };
u.id = 2;            // ✗ Cannot assign to 'id' (read-only)
u.name = 'Lin';      // ✓
```

`readonly` is compile-time only — runtime can still mutate via casts. Pair with `Object.freeze()` for true immutability.

## as const

```ts
const config = { port: 3000, host: 'localhost' } as const;
// type: { readonly port: 3000; readonly host: 'localhost' }
```

Deeply freezes literal values into their narrowest types. Tuples become readonly tuples.
