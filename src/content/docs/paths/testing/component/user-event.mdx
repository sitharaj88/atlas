## userEvent — high-level, realistic

```ts
import userEvent from '@testing-library/user-event';

const user = userEvent.setup();
await user.click(button);
await user.type(input, 'hello');
await user.tab();          // shift focus
await user.keyboard('{Enter}');
```

Simulates the **full** sequence of events a user causes (focus → keydown → keyup → input → click → ...).

## fireEvent — low-level

```ts
fireEvent.click(button);
fireEvent.change(input, { target: { value: 'hello' } });
```

Fires a single synthetic event. Faster but less realistic — bypasses focus, hover, etc.

## When to use each

- **userEvent** by default. Catches real bugs.
- **fireEvent** for precise scenarios — testing a single event handler in isolation.
