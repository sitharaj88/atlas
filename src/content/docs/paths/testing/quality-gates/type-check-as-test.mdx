## Add to CI

```yaml
- run: pnpm tsc --noEmit
- run: pnpm vitest --run
- run: pnpm eslint .
```

`tsc --noEmit` runs every line through the type checker and catches typos, missing args, null bugs — entire categories that runtime tests would never reach.

## Why it counts as testing

A test asks "does this case behave correctly?" — `tsc` asks the same about every code path simultaneously. A green `tsc` is a guarantee about the entire project.

## Strictness ratchets

Turn on flags one at a time:

- `strict: true` — baseline.
- `noUncheckedIndexedAccess: true` — `arr[0]` is `T | undefined`.
- `exactOptionalPropertyTypes: true` — explicit undefined handling.

Each adds confidence; each adds short-term work.
