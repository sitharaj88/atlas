## Stories as fixtures

```ts
import type { Meta, StoryObj } from '@storybook/react';
import { Button } from './Button';

const meta: Meta<typeof Button> = { component: Button };
export default meta;

export const Primary: StoryObj<typeof Button> = { args: { variant: 'primary', children: 'OK' } };
export const Disabled: StoryObj<typeof Button> = { args: { disabled: true, children: 'OK' } };
```

Each export is a state of the component. View in Storybook UI; reuse in tests.

## In tests

```ts
import { composeStories } from '@storybook/react';
import * as stories from './Button.stories';

const { Primary, Disabled } = composeStories(stories);

test('disabled button is disabled', () => {
  render(<Disabled />);
  expect(screen.getByRole('button')).toBeDisabled();
});
```

One source of truth for fixtures.

## When stories pay

- Shared component library across teams.
- Components with hard-to-reach states.
