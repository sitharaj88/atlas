## The minimum

```yaml
- run: pnpm install --frozen-lockfile
- run: pnpm lint
- run: pnpm tsc --noEmit
- run: pnpm vitest --run
- run: pnpm exec playwright install --with-deps
- run: pnpm exec playwright test
```

Order matters: cheap fast checks first, slow E2E last.

## Branch protection

In GitHub: Settings → Branches → require status checks before merging.

Don't add **manual gates** that humans bypass. Either it's required or it's not.

## Sharding for speed

E2E tests split nicely:

```yaml
strategy: { matrix: { shard: [1, 2, 3, 4] } }
- run: pnpm exec playwright test --shard=${{ matrix.shard }}/4
```

Tests that took 12 minutes serially run in 3.

## Detecting regressions

Run **the same suite** on `main` after merge — if main goes red, you know within minutes.
