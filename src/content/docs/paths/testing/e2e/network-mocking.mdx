## Network mocking

```ts
test('shows fallback on API failure', async ({ page }) => {
  await page.route('**/api/posts', (route) =>
    route.fulfill({ status: 500, body: '{"error":"oops"}' })
  );
  await page.goto('/blog');
  await expect(page.getByText(/couldn't load posts/i)).toBeVisible();
});
```

`page.route` intercepts. Decide: `fulfill` (mock), `abort` (block), `continue` (pass through).

## Visual snapshots

```ts
test('home looks right', async ({ page }) => {
  await page.goto('/');
  await expect(page).toHaveScreenshot('home.png', { maxDiffPixels: 50 });
});
```

First run records the baseline. Subsequent runs diff against it. Updates: `pnpm exec playwright test --update-snapshots`.

## When to snapshot

- Stable, design-system-driven pages.
- After verifying a critical interaction.

## When NOT

- Pages with timestamps or live data.
- Animations (use `animations: 'disabled'`).
- Localized layouts unless you stable the locale.
