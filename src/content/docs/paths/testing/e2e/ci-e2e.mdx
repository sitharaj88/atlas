## Sources of flake

- **Race conditions** — assertions running before content arrives. Fix with auto-waiting (`expect(...).toBeVisible()`).
- **Time-of-day data** — tests that pass in the morning, fail at night.
- **Order-dependent state** — tests that depend on previous tests' side effects. Always reset.
- **Shared resources** — DB rows, accounts. Use per-test isolation.

## Standard tools

- **`retries: process.env.CI ? 2 : 0`** in Playwright config — flakes get a second chance, locally you get fast feedback.
- **`trace: 'on-first-retry'`** — capture trace files only when retrying.
- **Sharding** — split tests across CI runners. `--shard=2/4` runs the second quarter.

## A solid CI workflow

```yaml
- run: pnpm install
- run: pnpm exec playwright install --with-deps
- run: pnpm exec playwright test --shard=${{ matrix.shard }}/4
  env: { CI: 'true' }
- if: failure()
  uses: actions/upload-artifact@v4
  with: { name: traces-${{ matrix.shard }}, path: test-results }
```

Upload trace files on failure. Past-you will thank current-you.
