## Setup

```bash
pnpm add -D vitest
```

```json
// package.json
{ "scripts": { "test": "vitest" } }
```

## A test

```ts
// math.test.ts
import { describe, it, expect } from 'vitest';
import { add } from './math';

describe('add', () => {
  it('sums two numbers', () => {
    expect(add(2, 3)).toBe(5);
  });
});
```

`pnpm test` — watch mode by default. `pnpm test --run` for CI.

## What you get

- TypeScript out of the box.
- Native ESM.
- Jest-compatible matchers (`toBe`, `toEqual`, `toContain`, `toThrow`, ...).
- `vi.fn()` for mocks.
- UI mode: `vitest --ui`.
- Coverage via V8 (`vitest --coverage`).

## Common matchers

```ts
expect(x).toBe(y);                    // ===
expect(obj).toEqual({ a: 1 });        // deep equal
expect(arr).toContain(x);
expect(fn).toThrow('message');
expect(promise).resolves.toBe(x);
expect(promise).rejects.toThrow();
expect(spy).toHaveBeenCalledWith(x);
```
