## The three

- **Spy** — wraps a real function, records calls, behavior unchanged.
- **Mock** — replaces a function with a controllable double.
- **Fake** — a working alternative implementation (e.g., in-memory DB).

## Vitest

```ts
import { vi, expect, it } from 'vitest';

// Spy
const spy = vi.spyOn(obj, 'method');
obj.method('hello');
expect(spy).toHaveBeenCalledWith('hello');

// Mock function
const mock = vi.fn(() => 42);
mock();
expect(mock).toHaveReturnedWith(42);

// Mock module
vi.mock('./db', () => ({ getUser: vi.fn(() => ({ id: 1 })) }));
```

## Faking time

```ts
vi.useFakeTimers();
setTimeout(callback, 1000);
vi.advanceTimersByTime(1000);
expect(callback).toHaveBeenCalled();
vi.useRealTimers();
```

## Don't over-mock

Mock the **boundary**, not your own code. Mock the network (MSW), the clock, the file system. Don't mock your own modules — that tests the mock, not the code.
