## await your assertions

```ts
it('fetches user', async () => {
  const u = await getUser('1');
  expect(u.name).toBe('Ada');
});
```

Don't forget `async`/`await`. A test that returns a Promise must `await` for the assertions to wait.

## Resolves / rejects

```ts
await expect(getUser('1')).resolves.toEqual({ name: 'Ada' });
await expect(getUser('999')).rejects.toThrow('not found');
```

Cleaner than try/catch in tests.

## Fake timers + setTimeout

```ts
vi.useFakeTimers();
const cb = vi.fn();
setTimeout(cb, 1000);
expect(cb).not.toHaveBeenCalled();
vi.advanceTimersByTime(1000);
expect(cb).toHaveBeenCalled();
```

## Testing fetch

For unit tests, mock fetch:

```ts
global.fetch = vi.fn(() => Promise.resolve(new Response(JSON.stringify({ ok: true }))));
```

For component/integration tests, use MSW (next lesson).
