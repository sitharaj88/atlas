## Server

```ts
app.get('/events', (c) => {
  return new Response(new ReadableStream({
    start(controller) {
      const id = setInterval(() => {
        controller.enqueue(`data: ${Date.now()}\n\n`);
      }, 1000);
      c.req.raw.signal.addEventListener('abort', () => clearInterval(id));
    },
  }), { headers: { 'content-type': 'text/event-stream' } });
});
```

## Client

```ts
const es = new EventSource('/events');
es.onmessage = (e) => console.log(e.data);
```

## Why SSE wins

- Plain HTTP — works through proxies, CORS, auth, load balancers.
- Auto-reconnect built into `EventSource`.
- Native compression.
- No special infra.

## Best for

- LLM token streams.
- Live dashboards (server pushes, client doesn't reply).
- Notifications.
