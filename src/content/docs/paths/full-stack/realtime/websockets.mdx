## Server (Hono)

```ts
import { upgradeWebSocket } from 'hono/ws';

app.get('/ws', upgradeWebSocket((c) => ({
  onOpen: (e, ws) => ws.send('hello'),
  onMessage: (e, ws) => ws.send(`echo: ${e.data}`),
  onClose: () => console.log('disconnected'),
})));
```

## Client

```ts
const ws = new WebSocket('wss://atlas.dev/ws');
ws.addEventListener('open', () => ws.send('hi'));
ws.addEventListener('message', (e) => console.log(e.data));
```

## When WebSockets

- Chat, presence, collaborative editors.
- Live dashboards with sub-second updates.
- Real-time games.

## When NOT

- One-way streaming (SSE is simpler).
- Request/response (just use HTTP).
- Sporadic updates (polling or SSE often suffices).

## Production gotchas

- **Reconnection logic.** Networks drop; clients must reconnect with backoff.
- **Auth.** WebSockets don't have headers post-handshake — auth via the upgrade request or first message.
- **Scaling.** State is per-server. Use Redis pub/sub or a managed service to fan out.
