## What's good

- Largest ecosystem (npm).
- Built-in `fetch`, `WebSocket`, `Web Streams` (Node 18+).
- Native ESM (`"type": "module"`).
- Most jobs and resources are Node-flavored.

## What's still rough

- TypeScript needs a transpiler (or `--experimental-strip-types`).
- Module resolution legacy (`moduleResolution: 'NodeNext'` is the safe pick).
- Slower startup than Bun/Deno.

## Modern Node defaults

```json
// package.json
{
  "type": "module",
  "engines": { "node": ">=20" }
}
```

```bash
node --watch src/server.ts   # auto-restart on changes
node --env-file=.env src/server.ts  # load env without dotenv
```

`tsx` or Bun handle TS-on-the-fly when needed.
