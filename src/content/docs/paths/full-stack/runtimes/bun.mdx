## What's good

- 2–4× faster startup than Node.
- One tool: runtime + bundler + package manager + test runner.
- Native TS / JSX. No transpiler.
- Node-API compat — most npm packages "just work."
- Built-in `bun:sqlite`, `bun:test`, `Bun.serve()`.

## A server

```ts
Bun.serve({
  port: 3000,
  fetch(req) { return new Response('Hello from Bun'); },
});
```

## When Bun wins

- Dev iteration speed.
- Greenfield monorepos (one tool everywhere).
- Simple deployment (single binary).

## When to be careful

- Newer than Node — fewer years of production scars to learn from.
- Some platforms (older serverless) don't support Bun runtime yet.
