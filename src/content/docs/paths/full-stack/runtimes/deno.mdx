## What's good

- TypeScript runs natively. No build step for dev.
- Permissions: `deno run --allow-net --allow-read=. server.ts`. Opt in to what the program can access.
- URL imports + npm specifiers (`import x from 'npm:lodash'`).
- Built-in fmt, lint, test, bench, doc.
- Web Standards (Fetch, Streams) at the core.

## What's still rough

- Smaller ecosystem than Node (though npm: makes much of npm work).
- Some libraries need adapters.
- Less hiring/community.

## Hello server

```ts
Deno.serve({ port: 3000 }, (req) => new Response('Hello'));
```

That's the whole HTTP server.
