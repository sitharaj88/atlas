## Strings vs. JSON

```js
// ❌ unstructured
console.log(`User ${user.id} bought ${product.name} for $${total}`);

// ✓ structured
log.info({ userId: user.id, productId: product.id, total }, 'purchase');
```

Structured logs are queryable. "Show me all purchases > $1000 today" is instant.

## Pino — fast structured logging for Node

```ts
import pino from 'pino';
const log = pino();

log.info({ orderId, total }, 'order.created');
log.error({ err }, 'failed to send email');
```

Pino is the fastest Node logger and most providers (Logtail, Datadog, Grafana) accept its JSON output natively.

## What to log

- **Request ID / trace ID** — correlate requests across services.
- **User ID / org ID** — pivot logs per user.
- **Outcome / duration** — for everything that talks to the network.
- **Error stacks** — always. Pino auto-serializes Error objects.

## What NOT to log

- **Passwords, tokens, full credit card numbers, full user PII.**
- **HTTP request bodies of sensitive endpoints.**
- **Health check spam** — sample or filter.
