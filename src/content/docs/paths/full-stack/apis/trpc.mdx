## The shape

```ts
// server
import { initTRPC } from '@trpc/server';
const t = initTRPC.create();

export const appRouter = t.router({
  greet: t.procedure.input(z.string()).query(({ input }) => `Hello ${input}`),
  createPost: t.procedure.input(z.object({ title: z.string() })).mutation(async ({ input }) => {
    return await db.post.create(input);
  }),
});
export type AppRouter = typeof appRouter;
```

```ts
// client
import { createTRPCClient } from '@trpc/client';
const trpc = createTRPCClient<AppRouter>({ url: '/trpc' });

const greeting = await trpc.greet.query('Atlas');     // string
const post = await trpc.createPost.mutate({ title: 'A' }); // typed
```

The types travel directly — no codegen, no schema file.

## When tRPC

- Monorepo with TS-everywhere.
- Internal APIs (your client + your server).
- React/TanStack-Query first.

## When not

- Public API serving non-TS consumers.
- You need a versioned schema document.
