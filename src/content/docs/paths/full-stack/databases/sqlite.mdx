## What it is

A C library that implements a SQL database in a single file. No server, no network. The DB is `app.db`.

## Why production-worthy

- **Faster than network DB** for many workloads — no round-trips.
- **WAL mode** allows concurrent readers + one writer.
- **Litestream / Cloudflare D1 / Turso** replicate to remote storage / multi-region.
- Used in production by: SQLite.org's own site, Expensify, Notion (locally), countless others.

## When SQLite fits

- Single-server apps.
- Read-heavy workloads.
- Edge deployments (Turso replicates to every region).
- Per-user databases ("one tenant, one file").

## When it doesn't

- Many concurrent writers across machines.
- Need a managed service that auto-scales.
- Sharded multi-master.

## Connecting from Node

```ts
import Database from 'better-sqlite3';
const db = new Database('app.db');
db.pragma('journal_mode = WAL');
const users = db.prepare('SELECT * FROM users WHERE id = ?').get(id);
```
