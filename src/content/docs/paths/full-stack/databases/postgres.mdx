## Why Postgres

- Strong ACID, mature tooling.
- JSONB columns — document flexibility within SQL.
- Full-text search built in.
- pgvector for AI embeddings.
- LISTEN/NOTIFY for pub-sub.
- Excellent indexes (GIN, GiST, BRIN, HASH).
- Massive community, every cloud supports it.

## Modern hosting

- **Neon** — serverless Postgres, branching like git.
- **Supabase** — Postgres + auth + storage + realtime.
- **PlanetScale** (now Postgres-compatible).
- **Fly Postgres**, **Crunchy**, **AWS RDS**, **Cloud SQL**.

## Connecting from Node

```ts
import postgres from 'postgres';
const sql = postgres(process.env.DATABASE_URL!);
const users = await sql`SELECT * FROM users WHERE id = ${id}`;
```

`postgres` (porsager/postgres) is a tagged-template, type-aware client. Faster and friendlier than `pg`.

## Patterns to learn

- **Migrations.** Use Drizzle / Prisma / sqlc.
- **Connection pooling** — PgBouncer or your DB host's built-in pooler.
- **EXPLAIN ANALYZE** — always check query plans on slow queries.
