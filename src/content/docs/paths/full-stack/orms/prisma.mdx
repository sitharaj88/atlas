## Schema in its own DSL

```prisma
model User {
  id        Int      @id @default(autoincrement())
  email     String   @unique
  createdAt DateTime @default(now())
  posts     Post[]
}
```

`prisma migrate dev` generates SQL migrations.

## Queries

```ts
const u = await prisma.user.findUnique({ where: { email: 'a@b.com' } });
const created = await prisma.user.create({ data: { email: 'c@d.com' } });
const withPosts = await prisma.user.findFirst({ include: { posts: true } });
```

Excellent autocomplete; nested includes feel natural.

## Trade-offs

Pros: largest ecosystem, polished tooling (Prisma Studio), great DX, well-documented.

Cons: ships a Rust query engine binary (slower cold starts in serverless), generates a large client.

## When Prisma vs Drizzle

- **Prisma** — when you want batteries-included; team prefers DSL.
- **Drizzle** — when you want lighter, SQL-first, faster cold starts.
