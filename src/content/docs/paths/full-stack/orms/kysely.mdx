## A query

```ts
const users = await db
  .selectFrom('user')
  .where('email', '=', 'a@b.com')
  .select(['id', 'name', 'createdAt'])
  .execute();
```

You write SQL using a fluent API. Types come from a TS interface describing your schema.

## Why Kysely

- No abstraction beyond what SQL already does.
- No generated client.
- Works great with raw migrations (you write SQL).
- Fast cold start.

## Trade-offs

- More boilerplate than Prisma/Drizzle for simple cases.
- No "include relation" sugar — write the JOIN yourself.

## When Kysely

- You like SQL.
- You want zero-magic type-safety.
- You've outgrown an ORM and miss writing SQL.
