## Why Hono

- Built on `Request` / `Response` — runs on Node, Deno, Bun, Cloudflare, Vercel, AWS Lambda.
- Tiny core (under 20KB).
- First-class TypeScript including a typed RPC client (`hc<typeof app>`).
- Plugins for OpenAPI, validation (Zod), JWT, JSX rendering.

## A complete tour is in the dedicated lesson

For routing, validation, error handling, middleware, and tests, see [Build a REST API with Hono](/paths/full-stack/apis/rest-api-hono/).
