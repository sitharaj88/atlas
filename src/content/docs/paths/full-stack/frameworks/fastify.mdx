## A server

```ts
import Fastify from 'fastify';
const app = Fastify({ logger: true });

app.get('/health', async () => ({ status: 'ok' }));
app.post('/users', async (req) => { /* req.body is typed */ });

app.listen({ port: 3000 });
```

## What it gives you

- Built-in JSON schema validation per route.
- Plugins for everything: `@fastify/cors`, `@fastify/jwt`, `@fastify/swagger`, etc.
- Logging via Pino (fast, structured).
- Schema-driven serialization (faster than ad-hoc JSON.stringify).

## When Fastify

- Node-only deployment.
- Performance-sensitive HTTP server.
- You like JSON Schema for I/O validation.

## Hono vs Fastify

- **Hono** wins on portability (edge runtimes), tiny size, end-to-end types.
- **Fastify** wins on Node ecosystem depth, schema-driven perf, mature plugins.
