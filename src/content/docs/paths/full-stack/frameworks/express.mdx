## The shape

```js
import express from 'express';
const app = express();
app.use(express.json());
app.get('/health', (req, res) => res.json({ ok: true }));
app.post('/users', (req, res) => { /* req.body, res.json, res.status */ });
app.listen(3000);
```

Familiar middleware-pipeline pattern. Endless tutorials online.

## Why it's still around

- Massive ecosystem of middleware.
- Most tutorials and StackOverflow answers reference Express.
- Stable API since 2010.

## Why pick something else for new code

- Less type-safety than Hono/Fastify.
- Slower than Fastify for similar workloads.
- No built-in schema validation.

## In 2026

If you're starting fresh, pick Hono or Fastify. If you're maintaining an Express app, fine — it works. Don't migrate just for fashion.
