## Why queue?

A web request should respond in under 1s. Sending an email, generating a thumbnail, calling a slow third party — those don't fit. Push a job to a queue; a worker picks it up.

## Three options

**BullMQ (Redis-backed)** — most popular Node solution. Retries, schedules, priorities, UI.

```ts
import { Queue, Worker } from 'bullmq';
const queue = new Queue('emails', { connection });
await queue.add('welcome', { userId: '123' });

new Worker('emails', async (job) => {
  await sendWelcome(job.data.userId);
}, { connection });
```

**pgmq (Postgres-backed)** — uses Postgres as a queue. One less moving part if you already have Postgres. Cron-friendly.

**SQS (AWS)** — managed. Excellent for high-scale or AWS-heavy stacks.

## Cron-style scheduling

Most queues support delayed jobs and repeat patterns:

```ts
await queue.add('daily-digest', {}, { repeat: { cron: '0 9 * * *' } });
```

Or use a service: **GitHub Actions on schedule**, **Vercel Cron**, **Cloudflare Triggers**.
